# 设置分类与接入清单

更新日期：2026-11-08。当前 React 工作区使用 BoardUI 双栏设置弹窗，五个分组、22 个分类；底部账号与本机资料入口保留。登录是独立应用页面，不属于设置目录。本文先记录当前页面事实，再保留 2026-10-05 旧 DOM 设置页的历史说明。设置目录以 [workspace-settings-catalog.ts](../src/components/application/settings/workspace-settings-catalog.ts) 为准。

## 当前设置目录

工作区分组：

- **常规**：本机名称、存储状态，以及个人资料、模型、工具、设备、钩子、备份和快捷键入口。
- **个人资料**：编辑显示名称、介绍与网站，保存后用于当前本机账号菜单；不是在线账号资料。
- **外观**：浅色、深色或跟随系统；可选鼠尾草绿、蓝色、紫色和暖橙色强调色。账号菜单“偏好”中也可直接切换这两项，两处共用本机外观配置；设置页保存后立即应用，取消保留已保存值。键盘切换主题时从当前焦点选项中心以 820ms 圆形扩展呈现，指针操作从点击位置开始；强调色变化不触发主题动画。减少动态效果或浏览器不支持 View Transitions 时即时应用。旧字体、列表密度和减少动态效果等配置保留在备份中，当前没有开放对应控件。
- **数据与备份**：导出设置、替换前备份和损坏原文，校验、预览与恢复设置 JSON。

智能与工具分组：

- **模型与 API**：搜索、新增、编辑、删除和撤销本机模型配置；保存记录尚未驱动 Vite 聊天路由，也没有据此执行连接测试。
- **Agent**：保存模型、回复、推理、权限和上下文等默认值，待执行器接入后使用。
- **个性化**：保存自定义指令与记忆策略，尚未形成真实记忆采集或检索。
- **语音**：保存输入、识别、声音和上下文偏好；语音服务未接入。
- **工具与技能**：管理 MCP、技能目录与连接器配置；保存不安装、不连接、不执行工具。

桌面与设备分组：

- **Live2D**：保存未来桌面角色的显示、位置与交互偏好，尚无实际 Live2D 陪伴窗口。
- **电脑操作**：保存未来操作工具的应用范围与确认策略，不访问其他应用。
- **活动记录**：保存采集与保留策略，没有活动采集器或生产样例记录。
- **应用快照**：保存目标、格式、文本与提示音偏好，没有截图服务。
- **浏览器**：保存链接、地址栏与批注偏好，浏览器执行服务未接入。
- **设备与 SSH**：搜索、增删改连接记录、端口、用户名与身份文件引用；不连接主机或读取私钥。

开发分组：

- **Coding**：保存 Pi 项目、目录与验证默认值；Pi 和真实目录绑定仍待接入。
- **生命周期钩子**：搜索、增删改事件、命令与超时；保存不执行命令。
- **代码审查**：保存审查范围、触发条件和严重级别偏好；不读取仓库或发表评论。
- **Git**：保存分支、提交与 Pull Request 偏好；不执行 Git、不推送或合并。
- **工作树**：保存目录、清理和环境偏好；不创建或删除 Git 工作树。

应用分组：

- **快捷键**：只读列出当前输入框的 Enter、Shift + Enter，弹窗 Escape，以及设置 `⌘ / Ctrl + ,`；不是旧工作台的全部快捷键表。
- **关于**：实际版本、文档、反馈和许可证入口，不制造账号权益或执行结果。

## 当前导航、草稿与保存

侧栏“设置”打开常规分类；底部账号菜单的本机资料、模型与 API、工具和备份快捷入口打开对应分类，不再另设“全部设置”。账号菜单的主题与强调色直接修改外观配置，外观设置分类仍可从侧栏设置访问。登录动作进入独立 `#login` 应用页。账号页显示账号传输未启用，不发送请求或呈现二维码。`⌘,` / `Ctrl+,` 打开或关闭设置；关闭或 Escape 返回背后的工作台 / 联系人，不关闭其会话。当前弹窗不使用旧设置页的搜索与返回历史，不能照搬旧 `⌘K` 行为。

分类切换时已访问的页面保持挂载，本次设置窗口中的表单草稿不会因换分类而重新初始化。表单提供明确的保存与取消，验证失败保持输入并说明原因；重新打开设置会创建新的设置会话。

本机资料沿用 ConfigurationStore，不另造账号资料存储。14 组配置及模型、工具、设备、钩子四类记录使用 `nekopapa.settings.v1`；设置目录数量与存储配置组数量不是同一概念。记录编辑保持 ID，删除引用与撤销沿用既有配置契约。

模型和执行偏好只是保存的默认值，不授予权限、不启动进程。界面不得以“保存成功”代替模型连接、工具调用、SSH 或代码执行成功。主题模式与强调色是当前直接生效的外观能力，设置页取消保留已保存外观；账号菜单中的选择即刻保存。设置页若有未保存草稿，其他入口的变更会在保存时进行冲突检查，不静默覆盖。

设置写入失败时保留当前输入或待保存状态，并提供重试；读取损坏数据时先保留恢复原文，避免用默认值覆盖用户配置。跨窗口更新兼容机制不代表本轮已完成原生多窗口验证。

## 当前备份与模型服务边界

设置备份包含本机资料、外观、执行默认值及模型、工具、设备、钩子配置，**不包含联系人、聊天历史、附件或旧工作台索引**。工作台聊天历史的 JSON 导出是另一条入口，当前只覆盖工作台对话。

导入最大 1 MiB，先校验版本、字段、ID 与引用，再展示预览；取消不替换，确认前保留 `.previous` 备份，备份失败则不替换。导入不会连接服务或执行命令，也不清空联系人和聊天数据。

凭据字段只接受环境变量名或身份文件引用，不接收真实 API Key、密码或私钥。当前 `/api/chat` 由 [Vite 服务器适配](../scripts/boardui-chat-api.ts) 读取服务器环境变量；本机模型记录与该路由仍需正式绑定，静态 Tauri 安装包尚需独立常驻服务。

官方人物的人设提示词属于 Java 后端，人物资料不是桌面端本机模型设置。通用模型与官方服务分别检查状态；当前 Java 人物服务未接入，官方人物的发送、Enter 与重试均禁用，草稿和已有历史保留。后续只同步公开人物目录及能力状态，不把正式提示词正文放入本机设置或备份，见 [接入边界](official-companion-service.md)。

官方账号、额度与流水后端没有接入。扫码开始、轮询、资料与退出已按现有 Java 源码建立 `desktop-account-contract.ts` 与 `desktop-account-api.ts`；适配器仅接受显式传输，生产实例保持关闭，没有默认地址、`fetch`、后台轮询或凭据持久化。业务错误、取消、已消费回执与字段白名单通过独立夹具测试，不能代替线上或桌面原生验收。

账号菜单按账号、工作区、偏好和支持分组，保留登录、本机资料、模型与 API、工具与技能、数据与备份、帮助和反馈。偏好组内可切换主题模式（跟随系统、浅色、深色）及四种强调色，使用 BoardUI 控件并立即写入 `nekopapa.settings.v1` 中的外观配置；系统模式响应设备当前外观，选择的强调色应用于全局 accent token 和对应交互状态。语言使用 BoardUI Select 与独立 SVG 国旗，可选简体中文和 English；不使用 emoji，语言仍独立保存并兼容读取旧外观配置。外观写入失败时更改仅在当前窗口保留，原持久化值不变，菜单显示错误并提供重试；读取被阻止时不覆盖原始配置。除登录外的快捷入口打开既有设置页；登录打开独立应用页面，返回操作沿浏览器历史回到原工作区并保留挂载中的聊天草稿。账号接口适配器仍关闭；页面只说明服务未开放，不提供扫码、认证或伪登录状态。CloudQuotaSnapshot 是旧配额展示契约，不是 Java 云点余额 DTO，当前登录页不使用它。

实现位置：[设置弹窗](../src/components/application/settings/settings-modal.tsx)、[本机配置面板](../src/components/application/settings/nekopapa-configuration-settings.tsx)、[数据备份](../src/components/application/settings/nekopapa-data-settings.tsx)、[本机资料](../src/components/application/dashboard/dashboard-account-dialog.tsx)、[独立登录页与导航](../src/components/application/account/account-page-provider.tsx)。后续执行能力按 [开发任务清单](iteration-backlog.md) 接入，学习能力见 [自学规划](self-learning-plan.md)。

## 导航、表单与存储

入口为账号菜单、顶部首页菜单、`⌘,` / `Ctrl+,` 和全局搜索。账号菜单的「账号」「使用情况」也可直接进入对应子页。设置不创建内容标签，不改内容历史；关闭按钮、返回工作台、Escape 或关闭快捷键恢复原内容。

设置内的 `⌘K` / `Ctrl+K` 聚焦设置搜索。分类名、描述和关键词支持多词匹配；搜索框方向键进入分类、Enter 打开首项，分类上下键与 Home / End 移动焦点。各子页保留窗口内滚动，集合查询相互独立，无结果可以清除搜索。

常规与人物选择委托 `WorkspaceStore`，继续保存到 `nekopapa.workspace-shell.v1`。独立 `ConfigurationStore` 拥有 14 组配置和四类记录，使用 `nekopapa.settings.v1`；不复制工作台对象。表单使用明确的保存 / 取消，切页保留未保存草稿，保存校验失败保持输入并定位字段。当前外观页用模式选择、当前显示状态和强调色色样表达配置，不提供主题示意图或实时预览；保存后应用外观，取消不改变已保存外观。应用快照发送目标沿用旧的 `mini` 存储值以兼容已有设置，界面显示为 Live2D 陪伴窗口。

记录编辑保持同一 ID；模型删除取消相关默认引用，撤销恢复原记录与仍未重新指定的引用。字段校验、导入、恢复和跨窗口同步共用同一契约。保存失败保留内存更改并提供重试；初次读取失败先重读有效原件，损坏原件备份成功前不覆盖。未落盘的更改不会被其他窗口的数据静默替换。

导入最多 1 MiB，拒绝未知版本 / 字段、重复 ID、无效值与失效引用；预览不修改配置，确认前可取消。确认替换或恢复默认前保存 `.previous` 备份；备份失败不替换。旧预览的手动 Token 预算被丢弃，用户资料和已保存配置 ID 保留。

凭据字段只接受环境变量名或身份文件路径。页面不接收实际 API Key / 密码 / 私钥；安全凭据存储与读取属于未来宿主任务。HTTP 地址不接受内嵌凭据、查询参数或片段，密钥不进入 localStorage、导出、页面或日志。

## 云点与自定义 API 的边界

官方云端是可选服务；默认模型来源为自定义 API。当前账号、额度、流水均未接入，无认证请求、后台刷新或服务端写入。页面使用产品自己的 `CloudQuotaSnapshot` 展示契约，不导入 NekoBuddy DTO、不内置后端地址或共享服务密钥。

配额的总量、已用、剩余、周期与重置时间必须来自未来服务的有效响应。剩余百分比为本期剩余 / 本期总配额；缺失、零配额、非有限或矛盾数据不显示数值进度。钱包余额和累计发放不是本期配额，不能用它们制造百分比。测试数据只用于测试，不注入生产视图。

是否复用 NekoBuddy 身份、钱包或计费仍需独立评估；本机页面不作此架构承诺。公开客户端的鉴权、资源限制和私有计费边界见 [架构中的云端服务评估](architecture.md#云端服务接入评估待确认)。

## 模块和后续接入
