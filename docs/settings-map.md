# 设置分类与接入清单

更新日期：2026-11-11。当前 React 工作区使用 BoardUI 双栏设置弹窗，五个分组、28 个分类；底部账号与本机资料入口保留。登录是独立应用页面，不属于设置目录。本文先记录当前页面事实，再保留 2026-10-05 旧 DOM 设置页的历史说明。设置目录以 [workspace-settings-catalog.ts](../src/components/application/settings/workspace-settings-catalog.ts) 为准。

## 当前设置目录

工作区分组：

- **常规**：只放已经生效的对话与输入偏好，保存后立即生效：“新建对话”分区设置默认模式（Auto / 聊天 / 学习 / Agent）、新对话是否沿用当前项目（按项目 ID；已移除的项目不再沿用）、启动时打开空白对话或最近的对话；“输入”分区设置 Enter 发送或 ⌘/Ctrl+Enter 发送，首页与联系人输入框和快捷键页同步。通知、启动与更新两个分区标为“未接入”，只保存默认值。本机资料卡已移到“个人资料”，界面语言仍只在账号菜单中切换。
- **个人资料**：参照 BoardUI AI Profile 的结构，用已有基础组件组合（该模板为 Pro，本机无授权，未安装其源码）。从上到下：
  - 身份卡：强调色封面、大头像、名称、`@NekoID` 或“未登录”说明、套餐 / “本机资料”徽章、介绍和网站，以及“编辑资料”。未登录时显示本机资料；登录后由 `profileIdentity()` 用账号的 `userName`、`avatarUrl`、`nekoId`、`cloudPlanCode` 填入同一位置，本机名称作为后备。
  - NekoPapa 账号卡：如实显示“官方账号服务暂未开放”，“查看登录页”会先关闭设置再进入独立 `#login` 页，返回后焦点回到打开设置的控件。登录前不显示任何 NekoID、套餐或云点数值。
  - 本机使用：对话数、发送的消息、近一年活跃天数、最长 / 当前连续天数，近一年活跃热力图（周一在上，固定阈值 1–2 / 3–5 / 6–10 / 11+），以及按对话数排列的常用项目（显示项目名称与主要文件夹，旧对话的文件夹路径与项目 ID 合并计数）。数据只来自本机聊天记录，助手回复不计入，不会上传。
  - “编辑资料”在本页切换为表单，保存或取消后回到资料页并聚焦“编辑资料”；有未保存修改时关闭设置走统一的放弃确认。
- **消耗统计**（工作区分组，位于个人资料之后）：两张卡片，版式参照 BoardUI Contributions Card 与 Sankey Chart Card（两者均为 Pro，本机无授权，未安装源码，用已有 token、SegmentedControl、Select 与 SVG 组合）。
  - 今年消耗的 Token：今年 1 月 1 日至今的合计，去年同期有记录时显示增减百分比；累计 Token（及回复次数）、单日峰值（及日期）、输入 / 输出、最长连续使用天数；“活动”热力图可切换每日（53 周 × 7 天）、每周（53 格）、每月（近 12 个月），色阶相对所显示范围内的最大值分四档，打开时停在最新一周。
  - Token 流向：近 7 天 / 近 30 天 / 全部；左侧为来源（每个项目、“未归入项目”、“联系人”，超过 5 个折叠为“其他”），右侧为模型及占比（超过 6 个折叠为“其他”），悬停高亮并显示数值。所选范围没有记录时显示“{范围}没有记录到 Token 用量。”
  - 数据来自聊天接口在回复结束时写入助手消息 `metadata` 的用量（`chat-usage.ts`，只保存模型服务返回的计数，不估算），汇总逻辑在 `usage-stats.ts`、桑基图几何在 `usage-sankey-layout.ts`；更新前的回复、群聊回复和不返回用量的服务不计入。聊天记录未读完时显示读取中，没有任何记录时如实说明。

## 运行偏好的控件与分区布局

运行类设置不会通过字段名推断控件。配置 schema 为字段明确声明 BoardUI 呈现方式；普通输入、长文本、枚举、布尔、精确数值分别使用 `Input`、`Textarea`、`Select`、`Switch`、`NumberField`。有限且适合并排比较的策略选项使用 `SegmentedControl`；连续范围使用 `Slider`；项目目录字段只保留浏览器可提供的文件夹名称草稿，并明确提示 Coding 执行层尚未接入。各配置块可选择纵向或双列布局，长文本和目录控件在双列布局中跨列显示。表单保存、校验、冲突合并和取消由共享面板管理，字段类型和分区内容保持各自领域语义。

| 设置分区 | 专用控件与呈现 |
| --- | --- |
| Agent | 模型来源与模型配置使用 `Select`；回复详细程度、推理和策略用 `SegmentedControl`；模型与权限分为双列配置块。 |
| 个性化 | 指令用 `Textarea`；记忆与共享范围用 `SegmentedControl`；写作偏好和工具记忆用 `Switch`。 |
| 语音 | 未连接语音服务时，麦克风与声音标识保留为本机输入，不伪造设备枚举；语言使用 `Select`，上下文与录音用 `Switch`。 |
| Live2D | 角色尺寸和不透明度用带明确单位的 `Slider`；初始位置用 `SegmentedControl`；窗口行为用 `Switch`。 |
| 电脑操作 | 应用范围用逐行 `Textarea`；确认策略用 `SegmentedControl`；操作与锁屏偏好用 `Switch`。 |
| 活动记录 | 记录策略与保留期用 `SegmentedControl`；排除应用使用逐行 `Textarea`，并保留无采集服务的状态说明。 |
| 应用快照 | 发送目标用 `Select`；图片格式用 `SegmentedControl`；文本与提示音选项用 `Switch`。 |
| 浏览器 | 网页和本地地址打开位置、批注截图策略使用 `SegmentedControl`；完整网址使用 `Switch`。 |
| Coding | 默认工作目录有单独的目录名称选择器；模型使用 `Select`；运行时路径使用 `Input`，验证偏好使用 `Switch`，Coding 指令使用 `Textarea`。 |
| 代码审查 | 自动、完整和安全审查用 `Switch`；触发条件与严重级别用 `SegmentedControl`。 |
| Git | 分支前缀使用 `Input`；合并和结果呈现方式用 `SegmentedControl`；推送 / 草稿偏好用 `Switch`；提交与 PR 指引用 `Textarea`。 |
| 工作树 | 根目录使用 `Input`；更新和清理用 `Switch`；保留数量用有步进器的 `NumberField`，不伪装成滑块；环境说明使用 `Textarea`。 |

这些分区仍然是尚未接入运行服务时的本机默认值。设备枚举、Coding 执行层真实路径、执行、浏览数据和活动记录均不在表单中伪造；控件可编辑与保存不代表对应执行能力已经可用。

## 当前导航、草稿与保存

设置入口位于底部账号菜单（“设置”项，附 `⌘,` / `Ctrl+,` 提示），打开常规分类；侧栏不再单独放“设置”按钮，账号菜单也不再列模型、工具、备份等分类快捷入口。账号菜单的主题与强调色直接修改外观配置，外观设置分类仍可从“设置”访问。登录动作进入独立 `#login` 应用页。账号页显示账号传输未启用，不发送请求或呈现二维码。`⌘,` / `Ctrl+,` 打开或关闭设置；关闭或 Escape 返回背后的工作台 / 联系人，不关闭其会话。当前弹窗不使用旧设置页的搜索与返回历史，不能照搬旧 `⌘K` 行为。

分类切换时已访问的页面保持挂载，本次设置窗口中的表单草稿不会因换分类而重新初始化。表单提供明确的保存与取消，验证失败保持输入并说明原因；重新打开设置会创建新的设置会话。

设置弹窗关闭按钮、遮罩、Escape、`⌘,` / `Ctrl+,` 和设置页关闭动作共用未保存草稿确认。存在草稿时选择“放弃更改”才关闭并丢弃本次设置会话中的草稿；“继续编辑”保留所有已访问页草稿。各表单显式取消只放弃当前表单，然后仍检查其他设置页是否有草稿。

本机资料沿用 ConfigurationStore，不另造账号资料存储。19 组配置及模型、工具、设备、钩子四类记录使用 `nekopapa.settings.v1`；设置目录数量与存储配置组数量不是同一概念。记录编辑保持 ID，删除引用与撤销沿用既有配置契约。

模型和执行偏好只是保存的默认值，不授予权限、不启动进程。界面不得以“保存成功”代替模型连接、工具调用、SSH 或代码执行成功。主题模式与强调色是当前直接生效的外观能力，设置页取消保留已保存外观；账号菜单中的选择即刻保存。设置页若有未保存草稿，其他入口的变更会在保存时进行冲突检查，不静默覆盖。

设置写入失败时保留当前输入或待保存状态，并提供重试；读取损坏数据时先保留恢复原文，避免用默认值覆盖用户配置。跨窗口更新兼容机制不代表本轮已完成原生多窗口验证。

## 当前备份与模型服务边界

设置备份包含本机资料、外观、执行默认值及模型、工具、设备、钩子配置，**不包含联系人、聊天历史、附件或旧工作台索引**。工作台聊天历史的 JSON 导出是另一条入口，当前只覆盖工作台对话。

导入最大 1 MiB，先校验版本、字段、ID 与引用，再展示预览；取消不替换，确认前保留 `.previous` 备份，备份失败则不替换。导入不会连接服务或执行命令，也不清空联系人和聊天数据。

凭据字段只接受环境变量名或身份文件引用，不接收真实 API Key、密码或私钥。开发服务器上 `/api/chat` 与 `/api/model-test` 由 [Vite 服务器适配](../scripts/boardui-chat-api.ts) 调用 `src/app/api/chat` 的处理函数，读取服务器环境变量。桌面安装包没有本地服务器：`src/app/desktop-chat-runtime.ts` 在窗口内运行同一套处理函数，模型请求交给 Tauri 命令 `model_fetch`（`src-tauri/src/model_proxy.rs`）发出并流式返回；请求中只带凭据占位符，Key 由宿主从进程与登录 shell 环境中读取后填入，窗口只知道变量是否已设置及前 8 个字符。从访达打开的应用需要在登录 shell 配置（如 `~/.zshrc`）中设置变量，修改后需重启应用。

官方人物的人设提示词属于 Java 后端，人物资料不是桌面端本机模型设置。通用模型与官方服务分别检查状态；当前 Java 人物服务未接入，官方人物的发送、Enter 与重试均禁用，草稿和已有历史保留。后续只同步公开人物目录及能力状态，不把正式提示词正文放入本机设置或备份，见 [接入边界](official-companion-service.md)。

官方账号、额度与流水后端没有接入。扫码开始、轮询、资料与退出已按现有 Java 源码建立 `desktop-account-contract.ts` 与 `desktop-account-api.ts`；适配器仅接受显式传输，生产实例保持关闭，没有默认地址、`fetch`、后台轮询或凭据持久化。业务错误、取消、已消费回执与字段白名单通过独立夹具测试，不能代替线上或桌面原生验收。

账号菜单按账号、工作区、偏好和支持分组，保留登录、本机资料、模型与 API、工具与技能、数据与备份、帮助和反馈。偏好组内可切换主题模式（跟随系统、浅色、深色）及四种强调色，使用 BoardUI 控件并立即写入 `nekopapa.settings.v1` 中的外观配置；系统模式响应设备当前外观，选择的强调色应用于全局 accent token 和对应交互状态。语言使用 BoardUI Select 与独立 SVG 国旗，可选简体中文和 English；不使用 emoji，语言仍独立保存并兼容读取旧外观配置。外观写入失败时更改仅在当前窗口保留，原持久化值不变，菜单显示错误并提供重试；读取被阻止时不覆盖原始配置。除登录外的快捷入口打开既有设置页；登录打开独立应用页面，返回操作沿浏览器历史回到原工作区并保留挂载中的聊天草稿。账号接口适配器仍关闭；页面只说明服务未开放，不提供扫码、认证或伪登录状态。CloudQuotaSnapshot 是旧配额展示契约，不是 Java 云点余额 DTO，当前登录页不使用它。

## 导航、表单与存储

入口为账号菜单、顶部首页菜单、`⌘,` / `Ctrl+,` 和全局搜索。账号菜单的「账号」「使用情况」也可直接进入对应子页。设置不创建内容标签，不改内容历史；关闭按钮、返回工作台、Escape 或关闭快捷键恢复原内容。

设置内的 `⌘K` / `Ctrl+K` 聚焦设置搜索。分类名、描述和关键词支持多词匹配；搜索框方向键进入分类、Enter 打开首项，分类上下键与 Home / End 移动焦点。各子页保留窗口内滚动，集合查询相互独立，无结果可以清除搜索。

常规与人物选择委托 `WorkspaceStore`，继续保存到 `nekopapa.workspace-shell.v1`。独立 `ConfigurationStore` 拥有 19 组配置和四类记录，使用 `nekopapa.settings.v1`；不复制工作台对象。表单使用明确的保存 / 取消，切页保留未保存草稿，保存校验失败保持输入并定位字段。当前外观页用模式选择、当前显示状态和强调色色样表达配置，不提供主题示意图或实时预览；保存后应用外观，取消不改变已保存外观。应用快照发送目标沿用旧的 `mini` 存储值以兼容已有设置，界面显示为 Live2D 陪伴窗口。

记录编辑保持同一 ID；模型删除取消相关默认引用，撤销恢复原记录与仍未重新指定的引用。字段校验、导入、恢复和跨窗口同步共用同一契约。保存失败保留内存更改并提供重试；初次读取失败先重读有效原件，损坏原件备份成功前不覆盖。未落盘的更改不会被其他窗口的数据静默替换。

导入最多 1 MiB，拒绝未知版本 / 字段、重复 ID、无效值与失效引用；预览不修改配置，确认前可取消。确认替换或恢复默认前保存 `.previous` 备份；备份失败不替换。旧预览的手动 Token 预算被丢弃，用户资料和已保存配置 ID 保留。

凭据字段只接受环境变量名或身份文件路径。页面不接收实际 API Key / 密码 / 私钥；安全凭据存储与读取属于未来宿主任务。HTTP 地址不接受内嵌凭据、查询参数或片段，密钥不进入 localStorage、导出、页面或日志。

## 云点与自定义 API 的边界

官方云端是可选服务；默认模型来源为自定义 API。当前账号、额度、流水均未接入，无认证请求、后台刷新或服务端写入。页面使用产品自己的 `CloudQuotaSnapshot` 展示契约，不导入 NekoBuddy DTO、不内置后端地址或共享服务密钥。

配额的总量、已用、剩余、周期与重置时间必须来自未来服务的有效响应。剩余百分比为本期剩余 / 本期总配额；缺失、零配额、非有限或矛盾数据不显示数值进度。钱包余额和累计发放不是本期配额，不能用它们制造百分比。测试数据只用于测试，不注入生产视图。

是否复用 NekoBuddy 身份、钱包或计费仍需独立评估；本机页面不作此架构承诺。公开客户端的鉴权、资源限制和私有计费边界见 [架构中的云端服务评估](architecture.md#云端服务接入评估待确认)。
