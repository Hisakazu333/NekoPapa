## 导航、表单与存储

入口为账号菜单、顶部首页菜单、`⌘,` / `Ctrl+,` 和全局搜索。账号菜单的「账号」「使用情况」也可直接进入对应子页。设置不创建内容标签，不改内容历史；关闭按钮、返回工作台、Escape 或关闭快捷键恢复原内容。

设置内的 `⌘K` / `Ctrl+K` 聚焦设置搜索。分类名、描述和关键词支持多词匹配；搜索框方向键进入分类、Enter 打开首项，分类上下键与 Home / End 移动焦点。各子页保留窗口内滚动，集合查询相互独立，无结果可以清除搜索。

常规与人物选择委托 `WorkspaceStore`，继续保存到 `nekopapa.workspace-shell.v1`。独立 `ConfigurationStore` 拥有 14 组配置和四类记录，使用 `nekopapa.settings.v1`；不复制工作台对象。表单使用明确的保存 / 取消，切页保留未保存草稿，保存校验失败保持输入并定位字段。外观页提供主题示意图，保存后应用外观，取消不改变已保存外观。应用快照发送目标沿用旧的 `mini` 存储值以兼容已有设置，界面显示为 Live2D 陪伴窗口。

记录编辑保持同一 ID；模型删除取消相关默认引用，撤销恢复原记录与仍未重新指定的引用。字段校验、导入、恢复和跨窗口同步共用同一契约。保存失败保留内存更改并提供重试；初次读取失败先重读有效原件，损坏原件备份成功前不覆盖。未落盘的更改不会被其他窗口的数据静默替换。

导入最多 1 MiB，拒绝未知版本 / 字段、重复 ID、无效值与失效引用；预览不修改配置，确认前可取消。确认替换或恢复默认前保存 `.previous` 备份；备份失败不替换。旧预览的手动 Token 预算被丢弃，用户资料和已保存配置 ID 保留。

凭据字段只接受环境变量名或身份文件路径。页面不接收实际 API Key / 密码 / 私钥；安全凭据存储与读取属于未来宿主任务。HTTP 地址不接受内嵌凭据、查询参数或片段，密钥不进入 localStorage、导出、页面或日志。

## 云点与自定义 API 的边界

官方云端是可选服务；默认模型来源为自定义 API。当前账号、额度、流水均未接入，无认证请求、后台刷新或服务端写入。页面使用产品自己的 `CloudQuotaSnapshot` 展示契约，不导入 NekoBuddy DTO、不内置后端地址或共享服务密钥。

配额的总量、已用、剩余、周期与重置时间必须来自未来服务的有效响应。剩余百分比为本期剩余 / 本期总配额；缺失、零配额、非有限或矛盾数据不显示数值进度。钱包余额和累计发放不是本期配额，不能用它们制造百分比。测试数据只用于测试，不注入生产视图。

是否复用 NekoBuddy 身份、钱包或计费仍需独立评估；本机页面不作此架构承诺。公开客户端的鉴权、资源限制和私有计费边界见 [架构中的云端服务评估](architecture.md#云端服务接入评估待确认)。

## 模块和后续接入

`settings-model.ts` 管理目录与临时历史；`settings-view.ts` 装配各子页；表单、管理列表、账号与额度按视图职责拆分。`configuration-actions.ts` 协调草稿和页面输入，记录动作与导入导出分别由 `configuration-record-actions.ts`、`configuration-transfer-actions.ts` 管理。类型、契约、默认字段和存储分开；`appearance.ts` 管理真实视觉生效。归档 / 回收站继续使用 `lifecycle-actions.ts`。

运行能力按 [开发任务清单](iteration-backlog.md) 接入：模型与凭据 CHAT-01，Pi 与目录 PI-01–PI-03，桌面与记忆 DESK / MEM，工具与工作流 FLOW / AUTO。页面配置完成不代表这些任务已验收。接入后需验证成功、拒绝、超时、取消、恢复和已保存默认值的实际生效，已有内容、ID 与正在运行的配置快照保持稳定。

本轮验证记录见 [导航闭环](navigation-contract.md)；原生、真实 Agent 与数据服务的后续验收见 [验收与交付](acceptance.md)。
