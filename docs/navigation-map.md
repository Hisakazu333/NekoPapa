# 当前工作区导航与历史职责

更新日期：2026-11-09。本节按当前 React 入口及其调用链记录事实；后半部保留旧 DOM 导航壳的职责矩阵，旧标签、分组、归档和回收站不能据此视作当前入口功能。实际验收另按日期和运行环境记录。

## 当前入口与状态归属

[main.ts](../src/main.ts) 渲染账号页、AgentChat、主题与设置提供器，根路径和 `/chat.html` 使用同一入口。侧栏主要结构保留，固定入口为“工作台”“联系人”“学习”，其后是“更多”面板（空间、知识库、小屋，均可用图钉固定到主导航，固定状态保存在 `nekopapa.sidebar-pins.v1`）；学习与知识库页面依赖尚未连接的 NekoBuddy 后端，只显示“后端未连接”和计划中能力。“空间”参照 Codex 资料空间：左侧分类（全部、对话、项目、文件、生成内容、图像、笔记，底部回收站），右侧标题、搜索框、最近 / 收藏 / 本机 / 云端范围与“名称 / 来源 / 上次活动”列表；尚未接入数据源，搜索禁用，所有列表显示说明将来内容的空状态，不显示示例数据。“小屋”是同伴的 Live2D 房间，仓库中还没有人物模型，页面只显示“Live2D 模型尚未提供”与计划中能力，不加载模型。项目不是单独页面，只由侧栏“项目”分区承担（见下文）；底部账号菜单是本机资料入口，主题和强调色选择位于账号菜单的“偏好”组，不另设侧栏主题入口。模式切换只切换显示，不创建新的会话、不把 contact.id 当作 thread.id。账号菜单的登录动作进入独立 `#login` 页面；登录页显示时 AgentChat 仍挂载但不可交互，返回恢复原页面、会话和草稿。

工作台和联系人容器保持挂载，切换模式不主动重置其当前页面状态。联系人内部已打开的会话也保持挂载，输入草稿、状态与流式内容分别归属该联系人组件。此行为只覆盖当前页面生命周期，不承诺刷新、崩溃或应用重启后恢复未发送草稿与进行中的执行。

侧栏导航下方是一个“对话”分区，所有工作台对话只出现在一处：先列本地项目（置顶项目在最前，其余有对话的按最新对话排序，还没有对话的排在后面），每个项目一行，可展开为缩进的对话树（左侧引导线、标题与 `现在 / 34m / 5h / 2d / 1w` 时间徽标，每个项目最多 5 条，超出时显示“还有 N 个对话”并打开全部对话面板），空项目展开显示“还没有对话”；随后是未归入项目的对话（最多 6 条，超出显示“查看全部对话”）。分区标题右侧“+”从文件夹添加项目（桌面版直接打开系统文件夹窗口，浏览器预览输入完整路径；两者都先检查文件夹存在，已属于某项目的文件夹不重复添加）。悬停项目行出现“…”菜单与“在此项目中新建对话”：菜单提供置顶 / 取消置顶、编辑（“编辑项目”弹窗：名称、源文件夹列表——第一个为“主要”，其余可“设为主要”或移除，至少保留一个，可再添加文件夹；保存前不生效）和移除项目（确认后只从 NekoPapa 移除，不删除文件夹，其对话改列在未归入项目的对话中）。没有任何项目和对话时只显示一条提示。默认展开最近使用或包含当前对话的项目；侧栏收起时只显示文件夹与对话图标。联系人对话与空草稿不出现在此列表。Codex 菜单中的“分区”与“归档聊天”在本应用没有对应功能，未提供。

工作台首页工具栏在“联系人”左侧提供“项目”选择：可选本地项目（置顶在前，显示名称、文件夹数和主要文件夹的当前 Git 分支）或“不使用项目”，也可“添加文件夹…”从文件夹新建项目：桌面版打开系统文件夹窗口，浏览器预览输入完整路径。添加前在本机检查（桌面由 Tauri 命令 `inspect_project_folder`，预览由开发 / 预览服务器的 `POST /api/project-folder`），只有存在的文件夹以解析后的完整路径加入；不存在、不是文件夹、只有名称或无权限时在面板中说明原因，不保存。菜单每次打开时重新检查各项目的主要文件夹，显示 Git 分支（分离时显示提交，链接工作树标“工作树”）或不可用原因。所选项目的 ID 写入对话记录的 `project` 字段，仅用于分组；旧对话保存的是文件夹路径，按“哪个项目包含该文件夹”归入，首次加载时把尚无项目的旧路径各建为一个项目（只执行一次）。打开已有对话恢复其项目，新建对话沿用当前项目；项目被移除后对话不再归入任何项目。选择联系人时不显示此控件。项目保存在 `nekopapa.projects.v1`（首次读取由旧 `nekopapa.project-folders.v1` 各建一个项目），侧栏、首页选择器、编辑弹窗与个人资料共用同一份页面内状态，写入失败时在面板中提示。只读取文件夹元数据和 `.git/HEAD`，不列出文件、不执行命令，也不代表 Coding 工具或后端已接入。

当前侧栏快速搜索用于筛选导航项，不是旧全局内容搜索。桌面宽度下可收起侧栏为图标栏，也可完全隐藏：标题栏最左侧（返回按钮前）的侧栏按钮或 `⌘B` / `Ctrl+B` 隐藏或显示整个侧栏，工作区随之占满左侧；选择保存在本机 `nekopapa.sidebar-hidden.v1`，重新打开时保持，读写失败时按显示处理且不影响本次切换（`src/app/sidebar-visibility.ts`、`use-sidebar-visibility.ts`）。按钮的提示框附带快捷键。标题栏“前进”与标签之间是垃圾桶按钮“关闭全部标签”：关闭所有打开的标签，只留一个新对话，前进 / 后退历史从它重新开始；只关闭视图，已保存的对话仍在侧栏对应项目中，完成后以提示说明；只有一个空白新对话或正在回复时禁用（`resetChatWorkspaceTabs`、`useChatWorkspaceTabs().closeAll`）。侧栏顶部收起按钮左侧是“邮件”按钮：邮件服务尚未接入，点按只显示不可用说明，不显示收件箱、未读数或示例邮件（`sidebar-mail-button.tsx`）。快速搜索可点按或用快捷键打开（修正：打开搜索的那次点击曾被外部点击监听当作“点外部”而立即关闭）。侧栏隐藏时，鼠标在窗口左缘或标题栏侧栏按钮上停留约 300ms 会把侧栏浮出覆盖在工作区上（点击该按钮才会常驻显示）（不挤压内容、不改变隐藏选择），离开侧栏约 300ms 后收回；Esc 或侧栏上的关闭按钮也可收回，浮出侧栏里打开的菜单或正在输入搜索时不收回（`sidebar-peek.tsx`）。“更多”面板同样支持悬停：停留约 150ms 打开，离开按钮与面板约 300ms 后关闭，悬停打开后再点击会保持打开；点击和键盘照常切换，键盘打开的面板不会因鼠标移开而关闭（`src/app/hover-intent.ts`、`use-hover-intent.ts`）。打开内置浏览器或目录 / 终端 / 更改 / 文件任一工具面板时，展开的侧栏临时收为图标栏，关闭后恢复；期间手动展开或收起则保留用户选择。窄窗口没有常驻侧栏，该按钮不显示；窄窗口从页面导航按钮打开抽屉，可通过关闭按钮或遮罩返回。侧栏当前选中项跟随页面模式。设置 → 外观 →“导航布局”可改为“底部悬浮栏”（外观字段 `navigation`，默认 `sidebar`）：不显示左侧栏、侧栏浮出和标题栏侧栏按钮，窗口底部居中显示悬浮栏（`workspace-dock.tsx`，由 `workspace-navigation.tsx` 按布局组装），分三组：主导航（工作台、联系人、学习、固定的页面与“更多”）｜“对话”“快速搜索”｜账号头像与“设置”。“更多”“对话”“快速搜索”在悬浮栏上方居中弹出面板（与侧栏同一套更多列表、对话列表和搜索结果；`⌘L` / `Ctrl+K` 打开搜索面板），选择后面板关闭，Esc 或点外部关闭并把焦点还给图标；在面板里打开删除对话等确认框时面板保持；头像打开账号菜单。悬浮栏模式不再从悬浮栏打开侧栏抽屉，窄窗口页面上的导航按钮仍打开抽屉。面板打开期间暂停放大，避免面板错位；鼠标靠近时图标按距离放大（最大 1.5 倍，`src/app/dock-magnification.ts`），悬停或键盘聚焦时在图标上方显示名称，减少动态效果时不放大；工作区底部留出 76px，悬浮栏不遮挡输入框。

## 工作台

首页呈现猫图标、按时段随机选一句的衬线问候（[chat-home-greeting.ts](../src/components/application/agent-chat/chat-home-greeting.ts)，六个时段各两句，打开首页时选定）、大文本输入区、工具区和快捷提示。输入区接受多行草稿，Enter 发送、Shift + Enter 换行；中文输入法组合期间不触发发送。模型未就绪或当前模式执行服务未接入时，保留输入能力并禁用发送。

模式选择位于输入框下层工具栏，与联系人选择同层；输入框内保留附件、权限、模型与发送控件。未选择联系人时默认 Auto，模式菜单提供 Auto、聊天、学习、Agent；Agent 统一处理通用任务与 Coding，不拆分为两个模式。模式选择只更新当前前端草稿状态，不填入提示词；Auto 路由、学习和 Agent 执行服务未接入，选择后明确阻止发送，不降级为普通聊天。

解释、写作、计划、研究快捷提示只填入输入草稿并聚焦文本框，不自动发送，也不启动代码执行、联网研究或工具。工具按钮打开工具设置，模型按钮展开模型菜单，其中“管理模型”进入已有设置。工作台联系人菜单选择后留在当前页面：若该联系人已有聊天，则按 `contact.id` 恢复其最新 `thread.id`；否则工作台与联系人页都会解析到同一个稳定会话 ID。发送时带上联系人设定，记录写入共享聊天历史；之后用户主动切到侧栏“联系人”时会直接打开当前选中的联系人。两处入口交错新增的消息会按消息 ID 合并。清除联系人选择回到普通工作台对话。

自建联系人可配置“专业提示词”，仅影响模型回复，不增加桌面工具、文件或命令权限；其模式提供聊天、学习、专业协助。官方人物的人设由 Java 后端维护，桌面端的姓名、简介和标签只用于公开展示，不拼装本地人设。用户不能修改官方提示词，仅能使用单人陪伴聊天和学习；选择官方人物后默认聊天，模式菜单仅提供聊天、学习。当前 Java 人物服务尚未接入，官方人物的发送、Enter 和重试均禁用并保留草稿，普通模型就绪不能代替官方服务就绪。学习模式可选为草稿状态，但学习服务未接入时禁止发送。后续同步与执行边界见 [Java 人物服务](official-companion-service.md)。

发出消息后显示工作台消息区、流式思考状态与后续输入区，停止入口交由当前 AI SDK 请求处理。未选择联系人的工作台对话不绑定联系人；右侧历史也只呈现无 contact 元数据的工作台会话。

顶部位置显示“工作台 / 当前对话标题”，当前没有消息时显示“新对话”。历史条目的选择沿用原 thread.id，读取时解除未读标记；重命名和未读切换修改同一记录。工作台流式期间禁止从历史切换会话或新建，避免把进行中的回复接到另一对话。

工作台边缘的展开按钮或标题栏右侧的“工作面板”按钮打开右侧辅助工作区（`chat-side-panel.tsx`），顶部用 PillTab 切换“历史 / 代码 / 资料”：历史是聊天历史；代码顶部是“环境”（`tools/chat-environment.tsx`：本电脑、项目与主要文件夹、当前 Git 分支与领先 / 落后、未提交更改数量——点击打开更改面板；窗口重新获得焦点时刷新；上下文用量照实说明需要聊天服务接入），下面是打开“更改 / 文件 / 终端”工具的入口，以及 Coding 智能体未接入的说明（Agent 的修改与命令尚未提供）；资料说明 NekoBuddy 后端未连接，列出计划中的引用资料 / 学习笔记 / 练习。后两者不显示示例文件或笔记。工作台标题栏中部显示已打开对话的标签（`chat-title-tabs.tsx`，标签列表由 `chatTabEntries` 推导），“新建对话”加号像浏览器的新标签按钮一样紧跟在最后一个标签之后（聊天页以外仍在返回 / 前进右侧）：点击切换，× 或鼠标中键关闭，←/→/Home/End 移动焦点，Delete 关闭；已删除的对话不再保留标签，回复生成中只能停留在当前标签。宽窗口拖动分隔条调整宽度，双击或 Enter 恢复默认，方向键微调、Shift 加大步长，Home / End 到达允许边界。窄窗口采用覆盖层，Escape、关闭按钮或遮罩可关闭并返回原焦点。关闭只收起辅助区，不删除聊天或停止请求。

## 联系人

点击侧栏“联系人”进入主工作区的联系人聊天页。同伴、搜索和新增均放在页内，侧栏不展开五位人物名单。左侧默认为 280px 的紧凑会话列表，包含官方预设和我的联系人；右侧是所选联系人的连续消息与矩形文本输入区。

产品统一称为“联系人”：新增、编辑、群聊选择、无障碍标签与错误提示沿用这一称呼。联系人是长期聊天对象，联系人的资料与聊天记录分别保存；内部组件与执行模块的技术命名不改变这一产品概念。

五位官方同伴为白羽澪、雪代凛音、花篠依織、霧宮栞和黒羽紬，沿用已有 ID。列表按姓名、简介和标签搜索，显示已有最后消息、时间或正在回复状态；没有消息时使用联系人简介，不伪造聊天内容。搜索无结果可清除搜索。

“群聊”“官方预设”“我的联系人”采用联系人分组标题：展开箭头、名称和人数，列表平铺，头像对齐；不使用文件夹图标或目录树竖线。箭头复用现有 BoardUI `ChevronDownSmall`，展开向下、收起向右。点击标题或用 Enter / Space 展开收起，不打开其他页面、不改变当前聊天。收起偏好单独保存在 `nekopapa.contacts.sections.v1`；搜索默认临时展开匹配分组，清空后恢复原偏好。偏好写入失败只影响下次恢复，不阻止本次收纳或聊天。

列表顶部小型“＋”展开“新建联系人”和“发起群聊”两项菜单。新建在同一工作区右侧打开联系人设置，名称必填，可填写标签、简介、专业提示词、回复语言和人物外观；验证或保存失败保留输入并说明原因。取消或关闭不创建联系人；创建成功后清除旧搜索、选择新联系人并回到聊天。官方人物的资料只读，不提供修改提示词、保存设定或基于官方人物复制设定的入口；新建联系人从空白设定开始。

自建联系人新建 / 编辑面板支持点击头像或导入按钮选择 PNG、JPG、WebP，单文件最大 5 MB。本机解码后居中裁剪为 256 × 256 并压缩，处理期间禁止保存；格式不支持、内容损坏或尺寸过大时保留上一次有效草稿并显示错误。同一文件可以重新选择。导入后切到头像预览，仍保留人物外观 ID；更换或移除先修改表单草稿，保存成功才提交，取消 / 关闭不改原头像，关闭也终止未完成处理。列表和单聊使用已保存头像，重载保留；群聊继续使用创建时的成员资料快照，不随之后编辑自动改写。

首次选择某联系人时，从共享历史按 updatedAt 选择最新的相同 contact.id 会话并保留原 thread.id；不存在时为该联系人建立独立连续会话。再次选择已打开联系人复用当前组件，不新建相同人的重复会话。

各联系人分别拥有输入、消息、错误和流式请求状态。切换联系人不把前一人的草稿、回复或重试请求挪给新联系人；工作台也保留自己的对话。点击对话标题打开右侧资料，官方人物显示“查看资料”，自建联系人提供编辑；窄窗口可返回联系人列表，返回后键盘焦点回到刚才选中的联系人或群聊行。

自建联系人行的更多菜单、右键 / Shift + F10 菜单及单聊标题更多菜单共用删除动作，官方人物不提供删除。确认框明确说明删除联系人及其全部单独聊天不可恢复，已有群聊与群消息保留，默认聚焦取消。取消 / Escape 不改变记录并返回有效入口。联系人写入失败时原资料与历史保留，确认框可明确重试；联系人已移除但历史清理写入失败时，界面说明部分完成并提供重试，删除标记阻止被删单聊重新显示。删除当前联系人卸载其会话并停止请求；工作台若选中了同一联系人则清除选择，其他联系人和群聊不受影响。

发起群聊仅能选择自建联系人；从自建联系人的单聊菜单发起时，该联系人默认已选。选择一位继续单独对话，选择 2–5 位建立群聊；没有自建联系人时说明新增方式。官方人物不显示群聊入口，存储创建与 API 校验同时拒绝官方人物加入群聊。包含官方人物的旧群聊仍能读取历史，但禁止发送及继续未完成轮次，不删除或改写已有记录。可用群聊记录独立保存，模型就绪后每轮按成员选择顺序依次回复；停止或失败保留已有消息，并提供“继续本轮”，未完成前禁止发送下一轮。群聊历史读取或保存失败会在联系人列表和当前聊天显示原因并提供重试。这不代表后台学习或研究工作流已接入。

每个群聊行和群聊页标题右侧的更多菜单共用“删除群聊”动作，空群和含官方人物的旧群也可删除。确认框默认聚焦取消；取消 / Escape 不删除，确认成功后移除该群与消息、卸载正在执行的群聊请求，返回有效列表入口。删除后台群不替换当前单聊；失败保留记录和确认框，需明确点击“重试删除”，普通保存重试不会暗中执行之前失败的删除。此删除不可恢复，确认框明确说明；不会删除成员联系人或其单独聊天。

输入区按文本、输入框内控件、下层工具栏分层：附件、权限策略、模型名称与箭头和圆形发送 / 停止按钮位于输入框内；模式与表情位于下层。权限按钮仅管理每次询问、仅查看或自动策略，不改变对话模式，也不代表工具执行已获授权。表情菜单锚定按钮，在光标处插入或替换选中文本后回到输入框；Escape / 外部点击关闭并恢复焦点。

工作台与联系人共用模型菜单：42px 供应商图标栏、紧凑模型行、小图标与右侧圆形选中标记，支持快速搜索、无结果与未配置空状态；“管理模型”进入已有设置。模型列表只来自真实本机配置和运行模型，图标副本位于 `public/boardui/composer-panel/models/`，源于参考页面已核实的 OpenAI、Anthropic、DeepSeek 静态 SVG。该菜单复用已引入的 BoardUI Dropdown，不代表安装了完整 Pro 源码。本机模型选择尚未驱动调用路由，官方人物的模型偏好也不会使 Java 人物服务变为可用。

工作台与自建联系人的添加菜单提供文件和文件夹、目标、计划模式，以及文档、电子表格、演示文稿和代码块插件。目标与计划只构成当前消息意图；文件仅暂存草稿，附件发送与文件生成未接入时明确阻止发送，移除选择后可恢复文字聊天。官方人物仅保留文件资料入口，不显示目标、计划或插件；其固定设定不受这些前端选项改写。输入支持 Enter 发送、Shift + Enter 换行和中文组合输入；发送条件为对应服务就绪、当前草稿无阻止原因、非空输入且该联系人当前不忙。运行时可停止，失败保留消息并提供该联系人的重试回复。

## 共享历史与本机存储

[ChatHistoryStore](../src/app/chat-history-store.ts) 是工作台与联系人共用的历史所有者。组件提交单条 ID 的更新、删除或元数据修改，存储读取最新内容后按 ID 合并，避免两个视图各自覆盖整份历史。历史使用 `nekopapa:chat-threads:v1`，兼容读取旧 `boardui:agent-chat-threads`，不主动删除旧原件。

联系人由 ContactsStore 管理，使用 `nekopapa.contacts.v1`；本机资料和设置由 ConfigurationStore 管理，使用 `nekopapa.settings.v1`。联系人记录、会话记录与账号资料分别拥有身份，不互相冒充。

联系人 v1 兼容新增可选 `avatarDataUrl` 和 `deletedIds`。头像只保存校验过的 PNG / JPEG / WebP data URL，单头像最多 100,000 字符，联系人存储总量最多 4,000,000 字符；派生头像地址不重复落盘。历史和群成员快照兼容读取导入头像，但发送 / 重试时共用请求序列化，剔除本机头像数据。删除标记与剩余联系人一次写入；迟到编辑不能恢复已删除联系人，共享历史读取和后续合并均排除其单聊。历史物理清理失败与联系人删除失败分别反馈，普通保存重试不会暗中删除未确认的联系人。

群聊由 GroupChatStore 管理，使用 `nekopapa.group-chats.v1`。v1 兼容新增可选 `deletedIds`，删除成功时和剩余记录一起保存；后续合并排除已删除 ID，丢弃其他入口的待写消息与迟到回复，避免恢复已删除群聊。删除失败不排队等待自动执行，原记录保留。该合并机制不提供数据库级跨窗口原子事务。

读取失败会保留已知会话并阻止覆盖损坏源数据；写入失败保留待写更新和当前页面内容，提供重试保存。消息通常在请求结束或停止后保存，流式中断的可靠恢复仍需后续运行与持久化契约。

共享存储与 storage 事件刷新是浏览器侧机制，不等于数据库事务、跨设备同步或原生多窗口并发已验收。浏览器和 Tauri WebView 的各自存储不自动共享。

| 置顶会话 / 取消置顶 | 普通或 Coding 会话进入 / 退出活动优先区 | 与收藏各自独立，保留会话 ID；归档与恢复保留置顶属性 |
| 标为未读 / 已读 | 改变会话的未读标记 | 不改变消息摘要、运行状态、活动时间或标签；打开会话时清除未读 |
| 分组内上移 / 下移 | 在目录树的组内内容中调整一位 | 对话、活动与最近访问自动排序，不提供此动作；首尾方向禁用 |
| 收藏上移 / 下移 | 在当前显示的收藏中调整一位 | 仅调整收藏引用，不改变组内内容顺序 |
| 归档 | 归档此内容并收起关联入口 | 显示已完成提示，可撤销；不删除磁盘文件 |
| 删除 | 确认后移入回收站，移除标签、收藏、最近访问及历史引用 | 可撤销或在回收站恢复原 ID；后台删除保留当前内容 |

## 会话活动视图

铃铛与 `⌥⌘U` 切换内侧栏视图，不增加通知标签、复制会话或改写内容历史。视图跨当前分类查看普通与 Coding 会话，页面不混入活动。关闭后恢复原分类与各自滚动位置；明确点击外侧分类或全局定位分组时返回该分类索引。收起侧栏后按活动快捷键，会展开活动侧栏。

| 控件 / 分区 | 动作与真实结果 |
| --- | --- |
| 优先级 | 显示置顶、等待确认、失败、运行中及未读会话；一条会话只出现一次 |
| 今天 / 昨天 / 过去七天 / 更早 | 由会话创建或 Agent 更新的真实时间分组，打开标签不刷新这个时间 |
| 历史会话 | 保留旧版没有时间的会话，不给迁移记录伪造「今天」时间 |
| 会话行 | 展示标题、所属空间或项目、已有摘要与状态；点击复用同一标签，并标为已读 |
| 活动视图选项 | 全部会话、只看未读、全部标为已读；无未读时禁用批量标记 |
| 未读空状态 | 提供「显示全部会话」；读完最后一条后焦点回到有效标签 |
| 更多 / 右键 | 共用内容管理菜单，增加置顶及未读标记；自动排序列表不显示分组内上下移动 |
| 人物选择、继续与底部新建 | 与普通侧栏共用人物偏好及按角色继续路径；活动中默认新建普通对话，项目上下文默认 Coding；不会因空间分类而偷偷创建笔记 |
| 标签状态 | 与侧栏引用同一会话元数据；关闭标签保留活动记录，归档移出活动，恢复保留元数据 |

`state.ts: recordSessionActivity(id, update, viewed)` 接受状态、真实更新时间与可选摘要；只更新已有普通 / Coding 会话（含归档记录），忽略回收站、无效、过期与完全重复事件。不自动新建会话或切换标签。已读只改变未读标记，不宣称 Agent 已停止或审批已完成。该接口供后续 Agent 适配层调用，当前没有运行中的模型、Coding 执行层或虚构活动事件。

活动偏好与元数据随工作台保存。排序由 `activity.ts` 派生，普通对话与工作台快捷索引由 `sidebar-model.ts` 派生，展示及事件由 `sidebar-view.ts` / `controller.ts` 处理。动态状态与摘要的浏览器验收使用独立测试夹具，不写入用户工作台。

## 设置、弹窗与即时提示

设置左侧按个人、陪伴、集成、Coding、内容管理和产品分组，共 28 个子页。设置有独立历史，顶部返回 / 前进只浏览设置；退出恢复原分类、内容和标签。`⌘,` / `Ctrl+,` 打开设置，设置中的 `⌘K` / `Ctrl+K` 聚焦设置搜索；Escape 或关闭快捷键返回工作台，不关闭背后的内容标签。分类上下键与 Home / End 移动焦点，Enter 打开分类。

常规选项委托已有工作台偏好：显示 / 隐藏内容侧栏、196–320px 宽度、5 / 10 / 20 项或全部、人物筛选、恢复分类顺序与最多四个固定功能。角色子页只保存所选人物，不创建或切换会话。保存失败有重试入口，各子页保留窗口内的滚动；工作台侧栏收起后设置仍可访问。完整选项与后续服务边界见 [设置清单](settings-map.md)。

配置表单保存 / 取消由独立 `ConfigurationStore` 管理；API、工具、设备和钩子支持搜索、增删改与最近删除撤销。导入先校验和预览，确认替换前备份，不改变工作台内容。外观即时预览和保存生效，其余执行策略仅保存默认值，尚未连接后端或执行器；云点展示依赖明确的产品配额契约。

| 控件 | 实际结果 | 允许边界 / 状态反馈 |
| --- | --- | --- |
| 设置 → 内容管理 | 管理归档 / 回收站，显示真实记录数 | `settings-actions.ts`；从账号菜单或顶部首页菜单进入，侧栏不保留管理按钮 |
| 设置分类切换 | 在右侧显示对应选项或管理列表 | 分类与内容历史分开；归档 / 回收站数量同步，查询按各集合保留 |
| 搜索内容结果 | 打开或复用真实内容标签 | 排除归档与回收站内容 |
| 搜索分组结果 | 侧栏定位分组，设置新建位置 | 进入分组所属的空间或项目目录，展开并定位该组；不替换活动内容、不新增标签 |
| 搜索首页结果 | 打开已有首页 ID | 首页不是分类按钮的隐式跳转 |
| 搜索人物结果 | 选择该人物并继续其普通会话，或打开创建表单 | 五位人物均可搜索；复用角色继续路径，不创建人物标签 |
| 搜索设置结果 | 打开对应的设置子页，包括归档 / 回收站 | 不新建系统标签，设置路由与真实内容 ID 分开 |
| 创建表单名称 / 保存到 | 填写内容名，选择允许的组 | 空白名称不通过；选择新建组才启用组名称字段 |
| 普通会话表单中的陪伴角色 | 展示打开表单时所选人物 | 提交绑定同一人物；取消不创建对象；Coding 和页面不绑定人物 |
| 创建 / 保存 | 提交已验证表单 | 创建组与条目一起提交；重命名只改名称 |
| 移动表单保存到 / 移动 | 选择合法归属并提交 | 只提供符合内容模式的目标，不改变内容 ID |
| 归档确认 / 取消 | 确认收纳分组，或不改数据关闭表单 | 取消为默认焦点 |
| 归档 / 回收站搜索 | 过滤名称、原归属与子项标题 | 各自保留查询；空结果和数量明确，不改变记录 |
| 设置管理列表内恢复 | 恢复内容或分组及该次子项 | 保留 ID、归属、顺序、人物和收藏；保留当前内容、查询及有效邻项焦点，不自动打开标签 |
| 删除确认 / 取消 | 确认移入回收站，或返回原管理入口 | 取消为默认焦点；关闭、Escape 或点击遮罩均不改数据 |
| 从归档中删除 / 从回收站恢复 | 归档记录移入回收站，恢复返回归档 | 同一对象及归档记录 ID、原归档时间保留，仍需另行恢复到常用列表 |
| 已归档提示中的撤销 | 恢复刚归档记录 | 共用正式恢复逻辑，不借用标签重开；撤销单内容时重新打开原 ID |
| 已归档提示中的查看归档 | 打开设置的归档子页 | 当前活动内容保留 |
| 已删除提示中的撤销 / 查看回收站 | 撤销当前删除或打开回收站 | 常用内容恢复原位置；来源为归档时恢复至归档 |
| 关闭提示 / 弹窗 / 取消 / Escape | 收起提示或取消操作 | 未提交表单无副作用，焦点回有效入口 |

创建、重命名、移动与搜索由 `content-actions.ts` 协调；归档、删除及恢复由 `lifecycle-actions.ts` 调用共享状态入口和 `overlays.ts: dialog / menu`。`lifecycle-view.ts` / `lifecycle.css` 呈现管理列表，`shell-notice.ts` 提供撤销与查看提示；`settings-model.ts` / `settings-view.ts` / `settings-actions.ts` 分别拥有设置目录与临时导航、页面和输入协调，不创建设置标签。读取保存数据异常时，原有存储提示提供原始 JSON 导出；该提示是数据恢复反馈，不扩展主页内容。

从新建菜单明确选择另一种内容并提交后，如果当前分类无法显示新内容，侧栏定位到可显示它的对话、空间或项目分类；工作台可以显示所有类型，因此保留工作台。取消表单仍保留原分类与内容。正常打开已有会话与切换标签不会触发这次创建定位。

## 拖动范围

| 拖动来源 | 有效目标 | 实际结果 | 不允许 |
| --- | --- | --- | --- |
| 外侧分类图标 | 其他四分类之前或之后 | 持久保存分类顺序 | 把固定布局、账号入口或静态标题混入分类 |
| 顶部标签 | 其他标签之前或之后 | 持久保存标签顺序，活动内容不变 | 拖成另一种内容或分组 |
| 空间分组 | 其他空间前后 | 同类空间排序 | 空间和项目互相转换 |
| 项目分组 | 其他项目前后 | 同类项目排序 | 项目移动到空间分组序列 |
| 组内普通会话 / 页面 | 内容行前后、允许分组或空组内部 | 组内排序或跨组移动 | 重置 ID、模式、收藏或复制记录 |
| 组内 Coding 会话 | 项目中的内容前后或项目内部 | 项目内排序或跨项目移动 | 移入空间 |
| 收藏行 | 其他收藏前后 | 仅收藏引用排序 | 通过收藏拖动修改实际归属 |

指针移动超过阈值后才进入拖动；拖动预览和目标提示由 `drag.ts` 提供，合法性及落地动作由 `controller.ts: dragDestination / drop` 与 `state.ts: reorder*` 处理。内容成功移入收起的分组后展开目标组，让用户看到新位置，活动内容保持不变。Escape、指针取消、失去窗口焦点或无效投放保持原数据；拖动释放后抑制误点击。关闭按钮、更多、展开箭头、输入框与宽度手柄不作为内容拖动把手。

## 保存与兼容

内容、归属、排序、收藏、归档、回收站和导航偏好由 `state.ts` 统一修改，`workspace-storage.ts` 负责保存与异常恢复，`workspace-records.ts` 校验归档 / 回收站快照；`workspace-lifecycle.ts` 共用捕获、移除分组与恢复规则。旧记录缺少 `trash` 时使用空回收站，既有 ID 不变；三个集合间内容 ID 必须互斥，损坏原文先备份，备份失败不覆盖源数据。当前角色用 `selectedCompanionId` 保存，旧数据缺失或无效时默认白羽澪；会话自身的 `companionId` 独立保留，包括旧的自定义角色 ID。角色目录和会话选择由 `companion-model.ts` 派生，头像与入口由 `companion-view.ts` / `companion.css` 呈现，菜单由 `companion-actions.ts` 处理，搜索及功能预设复用同一路径。

固定功能使用 `pinnedFeatures` 保存有效功能 ID：旧数据缺少该字段才使用默认项，明确保存的空列表不会重填；重复、未知 ID 和超过四个的尾项被过滤，其余内容保留。新版加载旧数据时清理空系统标签与分组占位标签，保留有效真实内容；损坏源数据先备份。当前 `localStorage` 保存的是导航与内容索引，浏览器和原生客户端各有一份。正文、Agent 运行数据及跨端同步属于后续模块。

`workspace-migration.ts` 一次性清理旧开发示例。只匹配固定旧 ID、原名称、类型、归属与未改动父组；已有未知字段、实际时间 / 摘要、非空闲状态、置顶 / 未读变化、改名或移动的记录保留。同名的新建记录也保留。清理覆盖常用列表、旧归档中的示例及标签、收藏、最近访问和分组上下文引用，不重新生成测试数据。空旧分组仅在无用户内容时移除；已完成清理的版本不会再次匹配。保存失败时源数据保留，当前窗口显示保存异常，重载可重试。

本矩阵描述实现职责，不代替本轮浏览器与原生验收；实际检查记录见 [导航闭环验收](navigation-contract.md)。
