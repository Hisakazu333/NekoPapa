# 侧栏与顶部栏的按钮职责

这份矩阵对应当前导航壳的可见按钮和实际事件处理。主区仍为占位；外栏预设桌面陪伴、角色、记忆、工作流、Agent 工作区、定时任务、模型与连接的用途说明与固定入口。未接入的能力标明状态，不创建系统占位标签或示例记录。可见的会话与页面是可保存的工作台索引，正文与运行模块尚未接入。

## 状态边界

| 状态 | 谁负责改变 | 不应产生的变化 |
| --- | --- | --- |
| 侧栏分类 | 外侧四类按钮；必要的搜索分组定位 | 不创建标签，不替换活动内容，不增加内容历史 |
| 新建位置 | 点击分组名、选择分组菜单、创建表单保存位置 | 不新建分组标签，不打开第一条会话 |
| 活动内容 | 内容行、标签、搜索内容结果、角色继续会话、内容历史 | 不复制内容，不把人物 ID 当作会话 ID |
| 归属 | 移动菜单、合法的内容拖放 | 不改变普通或 Coding 模式，不删除正文或磁盘目录 |
| 打开视图 | 顶部标签的打开、复用、关闭和恢复 | 关闭不归档或删除，已归档 / 删除的内容不借用关闭恢复 |
| 内容生命周期 | 内容 / 分组菜单；归档与回收站管理 | 归档和删除分别保存；恢复保留 ID，不复制对象，不清理项目目录 |
| 窗口呈现 | 顶部详情与完整视图按钮 | 不改写侧栏偏好、内容 ID、标签与运行状态 |
| 固定功能 | 「更多功能」图钉与预设弹窗的固定操作 | 只改变外栏固定列表，不改变分类、内容、标签或会话模式 |
| 当前陪伴角色 | 人物选择列表；明确选择人物的搜索动作 | 选择列表只保存偏好，不替换活动内容、不改已有会话角色；继续对话另行打开真实会话 |
| 列表偏好 | 侧栏列表选项 / 对话人物筛选 / 活动选项 | 只改变筛选和显示数量；不删除隐藏项、不切换内容、不改会话人物 |

分类与活动内容是独立状态。用户可以保持当前会话在顶部打开，同时切换侧栏查找笔记或其他项目。侧栏选中的内容行与标签引用同一真实 ID；没有处于当前分类的内容时，不制造一个虚假的选中会话。

## 顶部栏

| 可见控件 | 实际动作 | 允许边界 / 状态反馈 | 代码对应 |
| --- | --- | --- | --- |
| macOS 窗口按钮 | 由宿主关闭、最小化、全屏窗口 | 浏览器中的三色圆点仅为不可点击的预览装饰；原生按钮由 Tauri 配置提供 | `view.ts: renderShell`；`src-tauri/tauri.macos.conf.json` |
| 后退 / 前进 | 打开相邻有效内容历史记录 | 无记录时禁用；分类切换和分组展开不进入内容历史 | `controller.ts: click`；`state.ts: travel` |
| 侧栏按钮 | 展开或收起内侧栏 | 保留内容、分类、宽度和标签；隐藏后控件退出键盘顺序 | `toggleSidebar` |
| 标签标题 | 打开该标签对应的真实内容 | 重复打开复用同一个标签；当前标签有选中状态 | `open`；`state.ts: open` |
| 标签关闭按钮 / 中键 | 关闭该视图 | 后台关闭保持当前内容；当前关闭选相邻标签；只剩首页时不可关闭首页 | `closeTab`；`middleTabClick` |
| 加号 | 打开标签页菜单 | 创建内容、查找已有内容或恢复关闭的标签；选择后才执行 | `newMenu` |
| 右侧「…」 | 打开当前内容的操作菜单 | 跟随当前真实内容；首页提供工作台动作，不提供首页重命名 / 归档 / 删除 | `chrome-actions.ts: contentMenu` |
| 右侧详情图标 | 打开 / 关闭当前内容详情 | 展示类型、所属空间 / 项目、已有角色、收藏及真实活动；切换标签后同步 | `controller.ts: toggleDetails`；`chrome.ts: renderDetails` |
| 右侧展开图标 | 进入 / 退出完整视图 | 当前隐藏详情让内容占满工作区域；左侧导航保留，退出恢复详情；没有辅助视图时禁用 | `controller.ts: toggleFullView` |
| 右侧数字方框 | 查找、切换或关闭已打开的标签 | 按真实名称、分组、人物、类型或 ID 匹配；关闭保留内容和搜索条件，当前项及数量同步；唯一首页不可关闭 | `tab-picker.ts: show`；`tab-model.ts: openedTabEntries` |
| 标题栏空白区域 | 原生拖动窗口；双击按系统偏好缩放窗口 | 由 Tauri 运行时处理，与标签拖动、内容按钮分离；浏览器不模拟宿主窗口移动 | `data-tauri-drag-region`；Tauri 运行时 |

| 顶部新建菜单子动作 | 实际结果 | 允许边界 |
| --- | --- | --- |
| 新对话 | 打开普通会话创建表单 | 选择有效空间或项目，不改变已有会话模式 |
| Coding 会话 | 打开 Coding 创建表单 | 只能保存到项目；当前尚未调用 Pi |
| 新页面 | 打开页面创建表单 | 保存到空间或项目；当前不编辑正文 |
| 打开已有内容… | 打开全局搜索 | 内容结果打开真实 ID；组结果定位侧栏 |
| 恢复关闭的标签页 | 重开最近一组有效关闭标签 | 无关闭记录时禁用；已归档 / 删除内容不能重开 |

| 标签右键菜单子动作 | 实际结果 | 允许边界 |
| --- | --- | --- |
| 关闭标签页 | 关闭被点击的标签 | 唯一首页不可关闭 |
| 关闭其他标签页 | 保留被点击标签，关闭其余视图 | 按一次批量操作记录，内容仍保留 |
| 关闭右侧标签页 | 关闭当前顺序中右侧的视图 | 无右侧标签时禁用；拖动排序后按新顺序计算 |
| 恢复关闭的标签页 | 恢复最近关闭的一组 | 保留原 ID、顺序与有效内容，不恢复归档或回收站内容 |
| 标签左移 / 右移 | 调整单个标签顺序 | 边界方向禁用，活动内容不变 |
| 重命名 | 打开真实内容改名表单 | 首页不提供；不改变内容 ID |
| 移动到… | 打开真实内容归属表单 | Coding 只能去项目；后台操作不夺取活动内容 |
| 收藏 / 取消收藏 | 修改同一内容的收藏关系 | 不复制或删除内容 |
| 归档 | 收起真实内容并关闭相关视图 | 首页不提供；与关闭视图分开 |
| 删除 | 确认后将真实内容移入回收站 | 首页不提供；运行中 / 等待处理时禁用，不冒充停止 |

以上两组菜单由 `content-actions.ts: newMenu / openContextMenu` 处理，状态变化落到 `WorkspaceStore`。

右侧「…」的内容菜单提供重命名、移动、在侧栏中定位、收藏、会话置顶 / 未读、复制名称 / 实际 ID、归档和删除，生命周期动作由 `lifecycle-actions.ts` 在各入口共用；页面不提供会话置顶或未读。定位会显示真实父组、展开分区 / 子列表并聚焦条目，不打开其他内容或改变历史。首页菜单提供创建、搜索与设置；归档和回收站统一在「设置 → 内容管理」中管理。复制成功后才显示成功反馈，剪贴板写入失败提示失败。尚未接入的分享、新窗口、Pi 分支、执行进程、文件变更和资料来源不显示为可用功能。

标签管理的搜索框保留 Home / End 和左右键的文本编辑行为；上下键进入结果，左右键在打开与关闭按钮间切换，Enter 执行动作。关闭后保留查询并将焦点交给有效邻项，无匹配时返回搜索框。Escape 返回顶部数字按钮，Tab 离开菜单。顶部固定入口的弹窗不因标签带自动滚动而关闭；滚动中的行菜单仍随其锚点关闭。

完整视图与左侧栏开关分别处理：`⌘⇧F` 切换完整视图，`⌘B` 切换侧栏。Escape 优先关闭菜单 / 弹窗，其次退出完整视图并恢复详情，最后关闭详情。完整视图为当前窗口临时呈现，不改变已保存的侧栏可见性、宽度或导航分类。未来文件与变更工作区尚未实现，当前标签列表只列出现有首页、对话、Coding 与页面索引。

当前只有一个本地工作台，产品名称不承担工作区切换或通用管理菜单。分区加号负责添加空间 / 项目；归档与回收站管理位于设置，侧栏底部只保留新建入口；顶部侧栏按钮负责显示切换；外栏底部保留布局与账号入口。重复这些操作的品牌菜单已经移除；新的「更多功能」只收纳产品能力，不重复创建、归档或布局菜单。

功能菜单按陪伴、执行、连接分组，默认固定桌面陪伴、记忆、工作流。最多固定四个；取消全部固定后，重启仍保持为空。图钉是独立控件，操作后菜单保持打开且焦点返回相应图钉；菜单上下键选择功能，右方向键进入图钉，左方向键返回功能，Enter / Space 执行，Escape 关闭。预设弹窗可关闭或调整固定偏好，角色可调用原有继续会话流程，Agent 工作区可打开现有活动视图。七项用途及当前能力边界见 [功能预设](feature-presets.md)。

账号菜单沿用全局菜单的外部点击关闭、Escape 关闭与焦点返回。帮助子菜单可用右方向键进入、左方向键或 Escape 返回；在父菜单再次按 Escape 才关闭账号菜单。真实昵称、头像、会员状态与退出登录需在后续认证接入后显示，当前生产路径仅有未登录状态。

## 内侧栏：人物、查找与收纳

内侧栏按当前查找范围呈现一种主要列表。工作台用「角色 → 收藏 → 最近访问」收纳常用入口，条目右侧以弱色显示真实归属；空间和项目保留完整目录树，避免在工作台重复目录。对话按实际活动时间排列，已有摘要只占一行；没有摘要时不补空摘要。分区可折叠，空分区不在工作台占位。全空工作台仅显示一处简短引导；空间 / 项目的空状态保留可见加号。新用户的分区默认展开，已有折叠偏好保留。

| --- | --- | --- | --- |

| 重命名 | 修改分组名称 | 内容 ID、归属与标签不变，来源名称同步更新 |
| 上移 / 下移 | 在同类分组中移动一位 | 首尾方向禁用，不把空间变成项目 |
| 归档空间 / 项目 | 先显示包含条目的确认表单 | 取消不改变数据；确认归档组及当前子项 |
| 删除空间 / 项目 | 先显示当前子项数量，确认移入回收站 | 取消无变化；已独立归档 / 删除或移走的子项不包含，当前运行阻止删除 |

| 内容菜单子动作 | 实际结果 | 允许边界 |
| --- | --- | --- |
| 在标签页中打开 | 打开或复用同一内容标签 | 不新建会话 |
| 在侧栏中定位 | 展开并聚焦真实父组内的条目 | 跟随最新归属，不改变当前内容、人物或历史；归档条目不可定位 |
| 重命名 | 修改真实记录的标题 | 标签、侧栏、搜索同步；ID 保留 |
| 移动到… | 修改所属组 | 普通会话 / 页面可进空间或项目；Coding 只能进项目 |
| 收藏 / 取消收藏 | 添加或移除收藏引用 | 内容、归属和标签保留 |
| 置顶会话 / 取消置顶 | 普通或 Coding 会话进入 / 退出活动优先区 | 与收藏各自独立，保留会话 ID；归档与恢复保留置顶属性 |
| 标为未读 / 已读 | 改变会话的未读标记 | 不改变消息摘要、运行状态、活动时间或标签；打开会话时清除未读 |
| 分组内上移 / 下移 | 在目录树的组内内容中调整一位 | 对话、活动与最近访问自动排序，不提供此动作；首尾方向禁用 |
| 收藏上移 / 下移 | 在当前显示的收藏中调整一位 | 仅调整收藏引用，不改变组内内容顺序 |
| 归档 | 归档此内容并收起关联入口 | 显示已完成提示，可撤销；不删除磁盘文件 |
| 删除 | 确认后移入回收站，移除标签、收藏、最近访问及历史引用 | 可撤销或在回收站恢复原 ID；后台删除保留当前内容 |

## 会话活动视图

铃铛与 `⌥⌘U` 切换内侧栏视图，不增加通知标签、复制会话或改写内容历史。视图跨当前分类查看普通与 Coding 会话，页面不混入活动。关闭后恢复原分类与各自滚动位置；明确点击外侧分类或全局定位分组时返回该分类索引。收起侧栏后按活动快捷键，会展开活动侧栏。

| 控件 / 分区 | 动作与真实结果 |
| --- | --- |
| 优先级 | 显示置顶、等待确认、失败、运行中及未读会话；一条会话只出现一次 |
| 今天 / 昨天 / 过去七天 / 更早 | 由会话创建或 Agent 更新的真实时间分组，打开标签不刷新这个时间 |
| 历史会话 | 保留旧版没有时间的会话，不给迁移记录伪造「今天」时间 |
| 会话行 | 展示标题、所属空间或项目、已有摘要与状态；点击复用同一标签，并标为已读 |
| 活动视图选项 | 全部会话、只看未读、全部标为已读；无未读时禁用批量标记 |
| 未读空状态 | 提供「显示全部会话」；读完最后一条后焦点回到有效标签 |
| 更多 / 右键 | 共用内容管理菜单，增加置顶及未读标记；自动排序列表不显示分组内上下移动 |
| 人物选择、继续与底部新建 | 与普通侧栏共用人物偏好及按角色继续路径；活动中默认新建普通对话，项目上下文默认 Coding；不会因空间分类而偷偷创建笔记 |
| 标签状态 | 与侧栏引用同一会话元数据；关闭标签保留活动记录，归档移出活动，恢复保留元数据 |

`state.ts: recordSessionActivity(id, update, viewed)` 接受状态、真实更新时间与可选摘要；只更新已有普通 / Coding 会话（含归档记录），忽略回收站、无效、过期与完全重复事件。不自动新建会话或切换标签。已读只改变未读标记，不宣称 Agent 已停止或审批已完成。该接口供后续 Agent 适配层调用，当前没有运行中的模型、Pi 或虚构活动事件。

活动偏好与元数据随工作台保存。排序由 `activity.ts` 派生，普通对话与工作台快捷索引由 `sidebar-model.ts` 派生，展示及事件由 `sidebar-view.ts` / `controller.ts` 处理。动态状态与摘要的浏览器验收使用独立测试夹具，不写入用户工作台。

## 设置、弹窗与即时提示

设置左侧按个人、陪伴、集成、Coding、内容管理和产品分组，共 28 个子页。设置有独立历史，顶部返回 / 前进只浏览设置；退出恢复原分类、内容和标签。`⌘,` / `Ctrl+,` 打开设置，设置中的 `⌘K` / `Ctrl+K` 聚焦设置搜索；Escape 或关闭快捷键返回工作台，不关闭背后的内容标签。分类上下键与 Home / End 移动焦点，Enter 打开分类。

常规选项委托已有工作台偏好：显示 / 隐藏内容侧栏、196–320px 宽度、5 / 10 / 20 项或全部、人物筛选、恢复分类顺序与最多四个固定功能。角色子页只保存所选人物，不创建或切换会话。保存失败有重试入口，各子页保留窗口内的滚动；工作台侧栏收起后设置仍可访问。完整选项与后续服务边界见 [设置清单](settings-map.md)。

配置表单保存 / 取消由独立 `ConfigurationStore` 管理；API、工具、设备和钩子支持搜索、增删改与最近删除撤销。导入先校验和预览，确认替换前备份，不改变工作台内容。外观即时预览和保存生效，其余执行策略仅保存默认值，尚未连接后端或执行器；云点展示依赖明确的产品配额契约。

| 控件 | 实际结果 | 允许边界 / 状态反馈 |
| --- | --- | --- |
| 设置 → 内容管理 | 管理归档 / 回收站，显示真实记录数 | `settings-actions.ts`；从账号菜单或顶部首页菜单进入，侧栏不保留管理按钮 |
| 设置分类切换 | 在右侧显示对应选项或管理列表 | 分类与内容历史分开；归档 / 回收站数量同步，查询按各集合保留 |
| 搜索内容结果 | 打开或复用真实内容标签 | 排除归档与回收站内容 |
| 搜索分组结果 | 侧栏定位分组，设置新建位置 | 进入分组所属的空间或项目目录，展开并定位该组；不替换活动内容、不新增标签 |
| 搜索首页结果 | 打开已有首页 ID | 首页不是分类按钮的隐式跳转 |
| 搜索人物结果 | 选择该人物并继续其普通会话，或打开创建表单 | 五位人物均可搜索；复用角色继续路径，不创建人物标签 |
| 搜索设置结果 | 打开对应的设置子页，包括归档 / 回收站 | 不新建系统标签，设置路由与真实内容 ID 分开 |
| 创建表单名称 / 保存到 | 填写内容名，选择允许的组 | 空白名称不通过；选择新建组才启用组名称字段 |
| 普通会话表单中的陪伴角色 | 展示打开表单时所选人物 | 提交绑定同一人物；取消不创建对象；Coding 和页面不绑定人物 |
| 创建 / 保存 | 提交已验证表单 | 创建组与条目一起提交；重命名只改名称 |
| 移动表单保存到 / 移动 | 选择合法归属并提交 | 只提供符合内容模式的目标，不改变内容 ID |
| 归档确认 / 取消 | 确认收纳分组，或不改数据关闭表单 | 取消为默认焦点 |
| 归档 / 回收站搜索 | 过滤名称、原归属与子项标题 | 各自保留查询；空结果和数量明确，不改变记录 |
| 设置管理列表内恢复 | 恢复内容或分组及该次子项 | 保留 ID、归属、顺序、人物和收藏；保留当前内容、查询及有效邻项焦点，不自动打开标签 |
| 删除确认 / 取消 | 确认移入回收站，或返回原管理入口 | 取消为默认焦点；关闭、Escape 或点击遮罩均不改数据 |
| 从归档中删除 / 从回收站恢复 | 归档记录移入回收站，恢复返回归档 | 同一对象及归档记录 ID、原归档时间保留，仍需另行恢复到常用列表 |
| 已归档提示中的撤销 | 恢复刚归档记录 | 共用正式恢复逻辑，不借用标签重开；撤销单内容时重新打开原 ID |
| 已归档提示中的查看归档 | 打开设置的归档子页 | 当前活动内容保留 |
| 已删除提示中的撤销 / 查看回收站 | 撤销当前删除或打开回收站 | 常用内容恢复原位置；来源为归档时恢复至归档 |
| 关闭提示 / 弹窗 / 取消 / Escape | 收起提示或取消操作 | 未提交表单无副作用，焦点回有效入口 |

创建、重命名、移动与搜索由 `content-actions.ts` 协调；归档、删除及恢复由 `lifecycle-actions.ts` 调用共享状态入口和 `overlays.ts: dialog / menu`。`lifecycle-view.ts` / `lifecycle.css` 呈现管理列表，`shell-notice.ts` 提供撤销与查看提示；`settings-model.ts` / `settings-view.ts` / `settings-actions.ts` 分别拥有设置目录与临时导航、页面和输入协调，不创建设置标签。读取保存数据异常时，原有存储提示提供原始 JSON 导出；该提示是数据恢复反馈，不扩展主页内容。

从新建菜单明确选择另一种内容并提交后，如果当前分类无法显示新内容，侧栏定位到可显示它的对话、空间或项目分类；工作台可以显示所有类型，因此保留工作台。取消表单仍保留原分类与内容。正常打开已有会话与切换标签不会触发这次创建定位。

## 拖动范围

| 拖动来源 | 有效目标 | 实际结果 | 不允许 |
| --- | --- | --- | --- |
| 外侧分类图标 | 其他四分类之前或之后 | 持久保存分类顺序 | 把固定布局、账号入口或静态标题混入分类 |
| 顶部标签 | 其他标签之前或之后 | 持久保存标签顺序，活动内容不变 | 拖成另一种内容或分组 |
| 空间分组 | 其他空间前后 | 同类空间排序 | 空间和项目互相转换 |
| 项目分组 | 其他项目前后 | 同类项目排序 | 项目移动到空间分组序列 |
| 组内普通会话 / 页面 | 内容行前后、允许分组或空组内部 | 组内排序或跨组移动 | 重置 ID、模式、收藏或复制记录 |
| 组内 Coding 会话 | 项目中的内容前后或项目内部 | 项目内排序或跨项目移动 | 移入空间 |
| 收藏行 | 其他收藏前后 | 仅收藏引用排序 | 通过收藏拖动修改实际归属 |

指针移动超过阈值后才进入拖动；拖动预览和目标提示由 `drag.ts` 提供，合法性及落地动作由 `controller.ts: dragDestination / drop` 与 `state.ts: reorder*` 处理。内容成功移入收起的分组后展开目标组，让用户看到新位置，活动内容保持不变。Escape、指针取消、失去窗口焦点或无效投放保持原数据；拖动释放后抑制误点击。关闭按钮、更多、展开箭头、输入框与宽度手柄不作为内容拖动把手。

## 保存与兼容

内容、归属、排序、收藏、归档、回收站和导航偏好由 `state.ts` 统一修改，`workspace-storage.ts` 负责保存与异常恢复，`workspace-records.ts` 校验归档 / 回收站快照；`workspace-lifecycle.ts` 共用捕获、移除分组与恢复规则。旧记录缺少 `trash` 时使用空回收站，既有 ID 不变；三个集合间内容 ID 必须互斥，损坏原文先备份，备份失败不覆盖源数据。当前角色用 `selectedCompanionId` 保存，旧数据缺失或无效时默认白羽澪；会话自身的 `companionId` 独立保留，包括旧的自定义角色 ID。角色目录和会话选择由 `companion-model.ts` 派生，头像与入口由 `companion-view.ts` / `companion.css` 呈现，菜单由 `companion-actions.ts` 处理，搜索及功能预设复用同一路径。

固定功能使用 `pinnedFeatures` 保存有效功能 ID：旧数据缺少该字段才使用默认项，明确保存的空列表不会重填；重复、未知 ID 和超过四个的尾项被过滤，其余内容保留。新版加载旧数据时清理空系统标签与分组占位标签，保留有效真实内容；损坏源数据先备份。当前 `localStorage` 保存的是导航与内容索引，浏览器和原生客户端各有一份。正文、Agent 运行数据及跨端同步属于后续模块。

`workspace-migration.ts` 一次性清理旧开发示例。只匹配固定旧 ID、原名称、类型、归属与未改动父组；已有未知字段、实际时间 / 摘要、非空闲状态、置顶 / 未读变化、改名或移动的记录保留。同名的新建记录也保留。清理覆盖常用列表、旧归档中的示例及标签、收藏、最近访问和分组上下文引用，不重新生成测试数据。空旧分组仅在无用户内容时移除；已完成清理的版本不会再次匹配。保存失败时源数据保留，当前窗口显示保存异常，重载可重试。

本矩阵描述实现职责，不代替本轮浏览器与原生验收；实际检查记录见 [导航闭环验收](navigation-contract.md)。
