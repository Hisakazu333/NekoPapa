# 侧栏与顶部栏的按钮职责

这份矩阵对应当前导航壳的可见按钮和实际事件处理。主区仍为占位；外栏预设桌面陪伴、角色、记忆、工作流、Agent 工作区、定时任务、模型与连接的用途说明与固定入口。未接入的能力标明状态，不创建系统占位标签或示例记录。可见的会话与页面是可保存的工作台索引，正文与运行模块尚未接入。

## 状态边界

| 状态 | 谁负责改变 | 不应产生的变化 |
| --- | --- | --- |
| 侧栏分类 | 外侧四类按钮；必要的搜索分组定位 | 不创建标签，不替换活动内容，不增加内容历史 |
| 新建位置 | 点击分组名、选择分组菜单、创建表单保存位置 | 不新建分组标签，不打开第一条会话 |
| 活动内容 | 内容行、标签、搜索内容结果、角色继续会话、内容历史 | 不复制内容，不把人物 ID 当作会话 ID |
| 归属 | 移动菜单、合法的内容拖放 | 不改变普通或 Coding 模式，不删除正文或磁盘目录 |
| 打开视图 | 顶部标签的打开、复用、关闭和恢复 | 关闭不归档，归档恢复不借用关闭恢复 |
| 窗口呈现 | 顶部详情与完整视图按钮 | 不改写侧栏偏好、内容 ID、标签与运行状态 |
| 固定功能 | 「更多功能」图钉与预设弹窗的固定操作 | 只改变外栏固定列表，不改变分类、内容、标签或会话模式 |
| 当前陪伴角色 | 人物选择列表；明确选择人物的搜索动作 | 选择列表只保存偏好，不替换活动内容、不改已有会话角色；继续对话另行打开真实会话 |

分类与活动内容是独立状态。用户可以保持当前会话在顶部打开，同时切换侧栏查找笔记或其他项目。侧栏选中的内容行与标签引用同一真实 ID；没有处于当前分类的内容时，不制造一个虚假的选中会话。

| --- | --- | --- |
| 关闭标签页 | 关闭被点击的标签 | 唯一首页不可关闭 |
| 关闭其他标签页 | 保留被点击标签，关闭其余视图 | 按一次批量操作记录，内容仍保留 |

| 归档 | 收起真实内容并关闭相关视图 | 首页不提供；与关闭视图分开 |

以上两组菜单由 `content-actions.ts: newMenu / openContextMenu` 处理，状态变化落到 `WorkspaceStore`。

右侧「…」的内容菜单提供重命名、移动、收藏、会话置顶 / 未读、复制名称 / 实际 ID 和归档，复用侧栏的内容动作；页面不提供会话置顶或未读。首页菜单提供创建、搜索与归档管理。复制成功后才显示成功反馈，剪贴板写入失败提示失败。尚未接入的分享、新窗口、Pi 分支、执行进程、文件变更和资料来源不显示为可用功能。

完整视图与左侧栏开关分别处理：`⌘⇧F` 切换完整视图，`⌘B` 切换侧栏。Escape 优先关闭菜单 / 弹窗，其次退出完整视图并恢复详情，最后关闭详情。完整视图为当前窗口临时呈现，不改变已保存的侧栏可见性、宽度或导航分类。未来文件与变更工作区尚未实现，当前标签列表只列出现有首页、对话、Coding 与页面索引。

功能菜单按陪伴、执行、连接分组，默认固定桌面陪伴、记忆、工作流。最多固定四个；取消全部固定后，重启仍保持为空。图钉是独立控件，操作后菜单保持打开且焦点返回相应图钉；菜单上下键选择功能，右方向键进入图钉，左方向键返回功能，Enter / Space 执行，Escape 关闭。预设弹窗可关闭或调整固定偏好，角色可调用原有继续会话流程，Agent 工作区可打开现有活动视图。七项用途及当前能力边界见 [功能预设](feature-presets.md)。

账号菜单沿用全局菜单的外部点击关闭、Escape 关闭与焦点返回。帮助子菜单可用右方向键进入、左方向键或 Escape 返回；在父菜单再次按 Escape 才关闭账号菜单。真实昵称、头像、会员状态与退出登录需在后续认证接入后显示，当前生产路径仅有未登录状态。

## 内侧栏：人物、查找与收纳

内侧栏按当前查找范围呈现一种主要列表。工作台用「角色 → 收藏 → 最近访问」收纳常用入口，条目右侧以弱色显示真实归属；空间和项目保留完整目录树，避免在工作台重复目录。对话按实际活动时间排列，已有摘要只占一行；没有摘要时不补空摘要。分区可折叠，空分区不在工作台占位。全空工作台仅显示一处简短引导；空间 / 项目的空状态保留可见加号。新用户的分区默认展开，已有折叠偏好保留。

## 会话活动视图

铃铛与 `⌥⌘U` 切换内侧栏视图，不增加通知标签、复制会话或改写内容历史。视图跨当前分类查看普通与 Coding 会话，页面不混入活动。关闭后恢复原分类与各自滚动位置；明确点击外侧分类或全局定位分组时返回该分类索引。收起侧栏后按活动快捷键，会展开活动侧栏。

| 控件 / 分区 | 动作与真实结果 |
| --- | --- |
| 优先级 | 显示置顶、等待确认、失败、运行中及未读会话；一条会话只出现一次 |
| 今天 / 昨天 / 过去七天 / 更早 | 由会话创建或 Agent 更新的真实时间分组，打开标签不刷新这个时间 |
| 历史会话 | 保留旧版没有时间的会话，不给迁移记录伪造「今天」时间 |
| 会话行 | 展示标题、所属空间或项目、已有摘要与状态；点击复用同一标签，并标为已读 |
| 活动视图选项 | 全部会话、只看未读、全部标为已读；无未读时禁用批量标记 |
| 未读空状态 | 提供「显示全部会话」；读完最后一条后焦点回到有效标签 |
| 更多 / 右键 | 共用内容管理菜单，增加置顶及未读标记；自动排序列表不显示分组内上下移动 |
| 人物选择、继续与底部新建 | 与普通侧栏共用人物偏好及按角色继续路径；活动中默认新建普通对话，项目上下文默认 Coding；不会因空间分类而偷偷创建笔记 |
| 标签状态 | 与侧栏引用同一会话元数据；关闭标签保留活动记录，归档移出活动，恢复保留元数据 |

`state.ts: recordSessionActivity(id, update, viewed)` 接受状态、真实更新时间与可选摘要；只更新已有普通 / Coding 会话（含归档记录），忽略无效、过期与完全重复事件。不自动新建会话或切换标签。已读只改变未读标记，不宣称 Agent 已停止或审批已完成。该接口供后续 Agent 适配层调用，当前没有运行中的模型、Pi 或虚构活动事件。

活动偏好与元数据随工作台保存。排序由 `activity.ts` 派生，普通对话与工作台快捷索引由 `sidebar-model.ts` 派生，展示及事件由 `sidebar-view.ts` / `controller.ts` 处理。动态状态与摘要的浏览器验收使用独立测试夹具，不写入用户工作台。

## 弹窗与即时提示

| 控件 | 实际结果 | 允许边界 / 状态反馈 |
| --- | --- | --- |
| 搜索内容结果 | 打开或复用真实内容标签 | 排除归档内容 |
| 搜索分组结果 | 侧栏定位分组，设置新建位置 | 进入分组所属的空间或项目目录，展开并定位该组；不替换活动内容、不新增标签 |
| 搜索首页结果 | 打开已有首页 ID | 首页不是分类按钮的隐式跳转 |
| 搜索人物结果 | 选择该人物并继续其普通会话，或打开创建表单 | 五位人物均可搜索；复用角色继续路径，不创建人物标签 |
| 搜索归档结果 | 打开归档弹窗 | 不新建归档标签 |
| 创建表单名称 / 保存到 | 填写内容名，选择允许的组 | 空白名称不通过；选择新建组才启用组名称字段 |
| 普通会话表单中的陪伴角色 | 展示打开表单时所选人物 | 提交绑定同一人物；取消不创建对象；Coding 和页面不绑定人物 |
| 创建 / 保存 | 提交已验证表单 | 创建组与条目一起提交；重命名只改名称 |
| 移动表单保存到 / 移动 | 选择合法归属并提交 | 只提供符合内容模式的目标，不改变内容 ID |
| 归档确认 / 取消 | 确认收纳分组，或不改数据关闭表单 | 取消为默认焦点 |
| 归档搜索 | 过滤归档名、原归属与子项标题 | 空结果明确提示，不改变归档记录 |
| 恢复 | 恢复内容或分组及该次子项 | 保留 ID、归属、顺序和收藏；内容打开真实标签，分组只定位侧栏 |
| 已归档提示中的撤销 | 恢复刚归档记录 | 共用正式恢复逻辑，不借用标签重开 |
| 已归档提示中的查看归档 | 打开归档弹窗 | 当前活动内容保留 |
| 关闭提示 / 弹窗 / 取消 / Escape | 收起提示或取消操作 | 未提交表单无副作用，焦点回有效入口 |

创建、重命名、移动、搜索和归档由 `content-actions.ts` 调用 `overlays.ts: form / dialog / menu`。读取保存数据异常时，原有存储提示提供原始 JSON 导出；该提示是数据恢复反馈，不是新增主体页面。

从新建菜单明确选择另一种内容并提交后，如果当前分类无法显示新内容，侧栏定位到可显示它的对话、空间或项目分类；工作台可以显示所有类型，因此保留工作台。取消表单仍保留原分类与内容。正常打开已有会话与切换标签不会触发这次创建定位。

## 拖动范围

| 拖动来源 | 有效目标 | 实际结果 | 不允许 |
| --- | --- | --- | --- |
| 外侧分类图标 | 其他四分类之前或之后 | 持久保存分类顺序 | 把固定布局、账号入口或静态标题混入分类 |
| 顶部标签 | 其他标签之前或之后 | 持久保存标签顺序，活动内容不变 | 拖成另一种内容或分组 |
| 空间分组 | 其他空间前后 | 同类空间排序 | 空间和项目互相转换 |
| 项目分组 | 其他项目前后 | 同类项目排序 | 项目移动到空间分组序列 |
| 组内普通会话 / 页面 | 内容行前后、允许分组或空组内部 | 组内排序或跨组移动 | 重置 ID、模式、收藏或复制记录 |
| 组内 Coding 会话 | 项目中的内容前后或项目内部 | 项目内排序或跨项目移动 | 移入空间 |
| 收藏行 | 其他收藏前后 | 仅收藏引用排序 | 通过收藏拖动修改实际归属 |

指针移动超过阈值后才进入拖动；拖动预览和目标提示由 `drag.ts` 提供，合法性及落地动作由 `controller.ts: dragDestination / drop` 与 `state.ts: reorder*` 处理。内容成功移入收起的分组后展开目标组，让用户看到新位置，活动内容保持不变。Escape、指针取消、失去窗口焦点或无效投放保持原数据；拖动释放后抑制误点击。关闭按钮、更多、展开箭头、输入框与宽度手柄不作为内容拖动把手。

## 保存与兼容

内容、归属、排序、收藏、归档和导航偏好由 `state.ts` 统一修改，`workspace-storage.ts` 负责保存与异常恢复。当前角色用 `selectedCompanionId` 保存，旧数据缺失或无效时默认白羽澪；会话自身的 `companionId` 独立保留，包括旧的自定义角色 ID。角色目录和会话选择由 `companion-model.ts` 派生，头像与入口由 `companion-view.ts` / `companion.css` 呈现，菜单由 `companion-actions.ts` 处理，搜索及功能预设复用同一路径。

固定功能使用 `pinnedFeatures` 保存有效功能 ID：旧数据缺少该字段才使用默认项，明确保存的空列表不会重填；重复、未知 ID 和超过四个的尾项被过滤，其余内容保留。新版加载旧数据时清理空系统标签与分组占位标签，保留有效真实内容；损坏源数据先备份。当前 `localStorage` 保存的是导航与内容索引，浏览器和原生客户端各有一份。正文、Agent 运行数据及跨端同步属于后续模块。

`workspace-migration.ts` 一次性清理旧开发示例。只匹配固定旧 ID、原名称、类型、归属与未改动父组；已有未知字段、实际时间 / 摘要、非空闲状态、置顶 / 未读变化、改名或移动的记录保留。同名的新建记录也保留。清理覆盖常用列表、旧归档中的示例及标签、收藏、最近访问和分组上下文引用，不重新生成测试数据。空旧分组仅在无用户内容时移除；已完成清理的版本不会再次匹配。保存失败时源数据保留，当前窗口显示保存异常，重载可重试。

本矩阵描述实现职责，不代替本轮浏览器与原生验收；实际检查记录见 [导航闭环验收](navigation-contract.md)。
