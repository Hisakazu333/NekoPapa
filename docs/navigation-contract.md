# 侧栏与顶部栏：管理流程与验收

本轮开发侧栏、顶部栏、独立设置页与操作确认弹窗。工作台主区保持占位，不增加主页内容、分组概览、笔记正文、聊天输入或 Agent 运行界面。实际可见按钮及菜单动作见 [导航职责矩阵](navigation-map.md)。普通聊天、Pi、工作流、记忆和透明 Live2D 窗口仍按 [README](../README.md) 的后续迭代接入。

## 对象与职责

| 对象 | 当前职责 | 行为边界 |
| --- | --- | --- |
| 分类 | 工作台、对话、空间、项目四种侧栏索引 | 仅切换侧栏；不创建标签、不替换当前内容、不加入内容历史 |
| 空间 | 收纳普通会话与页面 | 可折叠、选择为新建位置、排序、重命名、归档、删除与恢复 |
| 项目 | 收纳 Coding 会话及相关普通会话、页面 | 当前管理工作台索引；真实目录绑定与 Pi 接入待开发 |
| 内容 | 普通会话、Coding 会话、页面 | ID 不随改名、移动、排序、收藏或恢复改变；模式属于会话自身 |
| 标签 | 已打开内容的视图 | 由首页或真实内容 ID 创建；重复打开复用，关闭保留内容 |
| 人物 | 五位正式角色的选择偏好与独立开始 / 继续对话入口 | 选择不替换当前内容；会话保留自己的角色；`lumia` 是白羽澪的兼容 ID，不是会话 ID |
| 归档 | 暂时退出常用列表的分组与内容 | 设置中的内容管理支持搜索与恢复；与关闭标签分开，不删除磁盘文件 |
| 回收站 | 被用户删除的分组与内容 | 确认后删除，从设置进入搜索与恢复；来自归档的对象恢复至归档，项目文件保持原状 |
| 设置 | 账号、顶部首页菜单、快捷键与全局搜索进入独立设置页 | 左侧分类，右侧真实选项；历史与内容分开，退出保留原标签；归档 / 回收站在内容管理中 |
| 侧栏布局 | 侧栏显示、宽度与分类顺序 | 已有偏好操作菜单，不通往空设置页面 |
| 账号区域 | 固定在最左下角，头像向上展开账号菜单 | 账号与使用情况进入对应设置子页；认证待接入，云点无数据时显示「—」，自定义 API 独立配置 |
| 活动视图 | 铃铛切换普通 / Coding 会话的活动索引 | 置顶、未读、真实时间分组与已有标签联动；不会创建另一份会话或占用主区 |

侧栏的分类、分组与内容不能互相代替。分类描述当前查找范围；分组描述内容归属与保存位置；会话是可以持续打开的真实记录。顶部标签和主区占位始终引用同一活动内容 ID，但侧栏分类可以独立切换以查找另一批内容。

点击分组展开箭头只改变显示。点击分组名展开并选择新建位置，不新建分组标签，也不切换正在看的内容。目录树仅在空间 / 项目分类显示；搜索、创建分组或撤销分组操作的定位会进入对应目录。设置管理列表内恢复保留当前内容及分类，不自动定位或打开标签。直接点击当前目录内的分组保持分类。

工作台集中显示人物、收藏和去重后的最近访问，空间 / 项目目录各自管理；普通对话采用真实活动时间列表，不显示 Coding 或页面。没有会话时人物入口显示「开始对话」，有会话时显示「继续对话」。普通对话的时间分区与铃铛活动视图各自保存折叠，打开标签可展开对应会话分区；浏览标签不伪造新活动时间。

对话索引可显示全部人物或仅当前所选人物。筛选只影响该索引，当前打开的其他人物会话仍保留原 ID、人物和标签；切换人物偏好会更新筛选范围，开始 / 继续另行执行。归档对象不进入筛选结果，无结果可返回全部人物。

目录子项、收藏、最近访问、对话和活动分区默认显示 10 项，可以改为 5 / 20 项或全部。显示限制不改源数据或排序；当前条目若位于限制之外，占用列表最后一个席位，真实剩余数量仍可展开。每个列表的临时展开独立，数量与人物范围偏好持久化，旧数据安全使用默认值。

顶部及条目菜单的「在侧栏中定位」依真实父组切换空间 / 项目索引，显示侧栏、展开分区与子列表并将焦点交给目标。定位不替换正在查看的内容、不打开新标签、不增加内容历史，也不改人物偏好。顶部数字按钮管理当前窗口实际打开的标签；搜索、关闭、归档与删除各有边界。

人物头像、名称和箭头只打开选择列表，选择后保存偏好，分类、活动内容、标签、历史和已有会话角色保持原值。独立的开始 / 继续按钮优先继续当前属于所选角色的普通会话，否则使用该角色最近访问或最近活动的普通会话；排除归档、Coding 和页面。没有记录则打开显示该角色的创建表单，取消无副作用。普通会话创建时绑定角色，后续切换不会改写它。

新建会话的记录 ID 与角色 ID 分开，收藏、最近访问、标签与归档引用会话 ID。搜索人物与角色功能预设共用选择和继续路径。五位人物来自官网正式设定；白羽澪和雪代凛音头像逐字节复制已有插画，其余三位使用名字占位并标注「头像待更新」，来源见 [人物资源](brand/lumia-avatar.md)。角色可选不代表已接入不同人物的模型配置或 Live2D。

当前条目保存的是工作台索引。创建、归档或恢复普通会话、Coding 会话与页面，不等于完成模型调用、聊天正文持久化、Pi 会话操作或笔记编辑。

## 验收场景

使用独立测试分组和内容，保留用户原有数据。以下为验收要求，不代表所有场景已经完成 GUI 验证。浏览器检查导航行为；原生 Tauri 窗口另行验证宿主行为。

### 分类、人物与真实会话

- [ ] 首次启动只有首页，无预置用户空间、项目或会话。
- [ ] 四种分类来回切换不增加标签，不改变活动内容与内容导航历史。
- [ ] 分类切换后显示正确内容：对话包含普通会话，空间包含空间内对话与页面，项目包含项目内各类内容。
- [ ] 点击内容、收藏、最近访问或搜索结果打开同一 ID；重复打开不产生另一标签或会话。
- [ ] 人物选择列表支持五位正式角色、上下键 / Enter、Escape 与焦点返回；只改变所选人物，不增加标签或改变当前会话。
- [ ] 独立继续入口使用所选人物的当前或最近普通会话；其他人物、归档和 Coding 会话不会被错误继续。
- [ ] 没有普通会话时，角色入口打开新建表单；取消不创建会话、标签或空分组。
- [ ] 普通会话表单显示并绑定打开时的角色；已有会话、归档恢复和详情保留原角色，刷新恢复选择偏好。
- [ ] 人物头像显示官网正式形象；未制作头像明确标注；显示名不暴露内部 Lumia 标识。
- [ ] 未接入的记忆、任务、连接器等功能仅展示用途和状态，不生成占位内容标签；铃铛打开活动侧栏，不弹出空通知菜单。

### 会话活动

- [ ] 铃铛开关和快捷键不改变当前标签、内容历史或分组展开；关闭恢复原分类与滚动位置。
- [ ] 只显示普通 / Coding 会话；全部历史可以访问，不局限于最近八条，也不复制优先区条目。
- [ ] 行内显示真实归属与已有摘要；运行中、等待确认、失败和未读来自同一会话元数据。
- [ ] 置顶与收藏分开；关闭标签不移除活动，归档移出，恢复保留 ID、摘要、置顶和活动时间。
- [ ] 打开会话复用标签并标为已读；不会把等待确认或运行中改成完成。
- [ ] 未读筛选、批量已读、读完后的空状态与恢复全部入口联动；后台状态更新不强制切换标签。
- [ ] 新建会话有实际创建时间；旧记录没有时间时保留在历史会话，不冒充新消息。
- [ ] 收起侧栏后用活动快捷键能重新显示活动；明确切分类或定位分组回到正常索引。
- [ ] 活动视图里的底部新建、角色入口、更多菜单、右键、搜索和标签共用真实会话记录。

### 列表收纳与顶部定位

- [ ] 全部人物 / 当前人物筛选只改变对话索引；切换人物后已有活动会话、ID 与标签保持，空结果可以恢复全部人物。
- [ ] 列表显示数量、人物范围能在重载后恢复；旧 / 损坏偏好逐字段回退，写入失败沿用原保存失败提示。
- [ ] 5 / 10 / 20 项和全部、展开剩余项与收起均不修改记录或排序，当前可见列表不隐藏正在打开的条目。
- [ ] 从顶部定位时，隐藏侧栏、收起分区与长列表都能展开到真实条目；移动后遵循新父组，后台条目定位不替换活动内容。
- [ ] 标签按实际名称、归属、人物、类型或 ID 查找；结果不受侧栏显示数量限制，也不列出尚未打开或已归档的内容。
- [ ] 查找结果关闭后台标签保留当前内容、查询和有效邻项焦点；关闭当前标签回到有效相邻标签，唯一首页受保护。
- [ ] 搜索框的文本编辑键、结果上下键、打开 / 关闭间左右键、Enter、Escape 与 Tab 均可使用，固定入口不会被标签自动滚动误关闭。

### 分组、创建与管理

- [ ] 点击分组名只展开并选择新建位置，当前内容、标签与历史不改变。
- [ ] 空组可以选择和创建内容；分组箭头、分区标题的展开与折叠不改变新建位置。
- [ ] 顶部加号、底部入口和分组菜单的创建种类、保存位置与表单说明一致。
- [ ] 缺少合适保存位置时，可以同时建立分组与内容；空白名称被拒绝，取消不留下记录。
- [ ] 重命名同步更新侧栏、标签与搜索，ID 与打开顺序不变。
- [ ] 移动保留 ID、模式、收藏和标签；操作后台内容不切换当前内容。
- [ ] 普通会话与页面可进入空间或项目，Coding 会话只能进入项目。
- [ ] 收藏使用同一内容 ID，取消收藏不删除内容。

### 搜索与内容历史

- [ ] 精确内容或分组标题优先于归属匹配，超过 20 个子项不会挤掉精确分组结果。
- [ ] 搜索内容打开真实 ID；搜索分组只定位侧栏，不创建标签。空组也可以定位。
- [ ] 工作台可以定位空间或项目组；不显示目标组的分类切到适合的分类，当前主区保留。
- [ ] 搜索支持上下键和回车；普通结果排除归档内容。
- [ ] 搜索中的人物与归档结果执行各自动作，不创建人物或归档标签。
- [ ] 前进、后退仅记录内容打开，不把纯分类切换或分组选择当作内容跳转。
- [ ] 关闭、归档与迁移后，历史不重新打开失效标签。

### 标签与拖动

- [ ] 标签可打开、切换、复用、左右移动与拖动排序；排序不改变内容 ID 或活动内容。
- [ ] 关闭后台标签保留当前内容；关闭当前标签选择有效相邻标签，关闭全部内容后回首页。
- [ ] 中键、关闭按钮、菜单和快捷键遵循相同关闭规则；关闭保留侧栏内容。
- [ ] 关闭其他、关闭右侧遵循当前排序；批量关闭作为一组恢复，归档内容不能借重开标签回到常用列表。
- [ ] 标签过多时通过列表切换，窗口缩放后当前标签保持可见。
- [ ] 外侧四类可以拖动排序，侧栏布局、账号入口与静态分类标题不参加排序。
- [ ] 分组只能在同类分组内排序，不通过拖动把空间变成项目。
- [ ] 内容可以在组内排序、跨允许的组移动，空组也有有效投放位置。
- [ ] 收藏内拖动只调整收藏顺序，不改变内容归属；最近访问按实际打开记录更新。
- [ ] 无效投放、Escape、失去焦点或取消指针不修改数据；拖动结束不误触发打开内容。
- [ ] 有拖动预览、投放提示与滚动支持；关闭、更多、展开箭头和宽度手柄不触发内容拖动。

### 归档、删除与恢复

- [ ] 归档内容从常用组、收藏、最近访问、普通搜索与标签移出；归档后台内容保留当前视图。
- [ ] 归档分组说明包含内容，取消不改数据，确认收纳该组及当前子项。
- [ ] 设置中的归档 / 回收站可搜索标题、原归属及分组子项标题，不新增标签；恢复 / 删除后分类数量更新，侧栏没有重复管理入口。
- [ ] 空归档有明确状态；关闭设置返回原视图与有效焦点。
- [ ] 恢复保留 ID、原归属、顺序和收藏；恢复分组包含该次归档的子项。
- [ ] 多次归档、恢复和重启不产生重复对象或悬空归属；缺失父组使用有效恢复位置。
- [ ] 归档项目不删除本地文件，不宣称暂停 Agent、删除 Pi 会话或修改长期记忆。
- [ ] 内容行、分组、顶部菜单和标签右键提供同一对象的归档 / 删除动作；全局管理从设置进入，首页不能删除。
- [ ] 删除默认焦点为取消；取消、关闭、Escape 与遮罩无数据副作用，从归档发起取消后保留原查询。
- [ ] 删除清理相关标签、收藏、最近访问及关闭恢复 / 导航历史；后台删除不替换当前内容，关闭恢复不能越过回收站复活内容。
- [ ] 删除分组仅包含当前仍在组内的内容；独立归档、删除或移走的子项不重复处理。运行中 / 等待处理的会话及包含它们的组不能删除。
- [ ] 回收站搜索覆盖名称、原归属与组内标题，空状态明确；从归档删除的内容恢复至归档，仍使用原记录与内容 ID。
- [ ] 管理弹窗恢复保留查询和有效邻项焦点，当前标签不改变；撤销删除可重新打开原内容，恢复不触发模型。
- [ ] 重载保留回收站、来源与顺序；旧版缺少回收站时保留已有内容，损坏记录先备份，写入失败不得显示为已落盘。

### 导航偏好、取消与保存

- [ ] 侧栏布局提供真实的展开或收起、宽度恢复、分类顺序恢复动作。
- [ ] 宽度拖动、双击、左右键和 Home 遵循 196–320px 范围与 232px 默认值。
- [ ] 菜单支持方向键、Escape、Tab 退出；取消表单返回有效入口；隐藏侧栏退出键盘顺序。
- [ ] 重启保留内容、分组、归档、回收站、收藏、分类、标签顺序与侧栏布局。
- [ ] 旧空系统标签与分组占位标签被清理，全部有效真实内容保留。
- [ ] 局部无效数据不丢弃其余内容；原始备份可导出；备份失败不覆盖源数据。
- [ ] 保存失败提供可见反馈，当前窗口可操作，但不把内存变更说成已经持久化。
