# 产品功能预设

更新日期：2026-10-04。本轮只补齐外侧栏的产品功能入口、用途说明和固定偏好，主内容保持原占位。真实 Agent、Live2D、记忆与工作流按 [迭代计划](iteration-plan.md) 接入。

## 收纳与操作

外栏上半部分仍为工作台、对话、空间、项目四类索引。「更多功能」放在四类之下，点击后在右侧展开菜单；分隔线以下放固定功能。布局与账号仍固定在底部。

默认固定桌面陪伴、记忆、工作流。菜单中每项的图钉独立于功能名称，可固定或取消，最多四项以适配当前最小窗口；取消全部后保持为空。偏好随工作台保存，刷新和重启恢复，不增加会话、项目、标签或最近访问记录。固定排序沿用添加顺序，当前不提供功能图标拖动。

点击功能打开紧凑的用途说明弹窗。尚未接入的能力标明「待接入」，不显示伪造运行、记忆、连接或任务。关闭或取消保持原内容；角色和 Agent 工作区提供已有流程的明确操作。

## 七个按钮分别做什么

| 功能 / ID | 产品用途 | 当前可执行操作 | 后续交付 |
| --- | --- | --- | --- |
| 桌面陪伴 `desktop-companion` | 在透明桌面窗口显示角色；拖动、隐藏、唤起，继续同一会话 | 查看用途说明、固定 / 取消；尚无显示 Live2D 的动作 | M3：透明窗口与故障恢复，不重复启动 Agent |
| 角色 `characters` | 选择陪伴人物，开始或继续该人物的交流 | 展示当前人物，切换五位正式角色并保存偏好；独立继续按钮复用其普通会话，无会话时打开创建表单 | M2 / M3：真实聊天、角色模型配置及 Live2D；角色 ID 与会话 ID 分开 |
| 记忆 `memory` | 用户决定长期保留哪些偏好与事实 | 查看用途说明、固定 / 取消；未产生记忆记录 | M3：确认、查看、修改、删除，与历史及压缩摘要分别管理 |
| 工作流 `workflows` | 普通 Agent 按步骤使用资料并形成成果 | 查看用途说明、固定 / 取消；未创建工作流或运行 | M5 / M6：首个摘要保存流程、模板、失败处理与重试 |
| Agent 工作区 `agent-workspace` | 独立查看真实任务、步骤和待确认操作 | 查看用途说明；「查看会话活动」打开已有活动侧栏，不创建工作区窗口 | M3 / M4：引用同一 Run，普通与 Coding 执行分别展示 |
| 定时任务 `schedules` | 为会话和工作流指定周期，查看每次结果 | 查看用途说明、固定 / 取消；没有创建定时器或后台任务 | M6：明确目标、暂停 / 恢复、休眠错过及冲突处理 |
| 模型与连接 `model-connections` | 配置普通 / Coding 模型及工具资料授权 | 查看用途说明、固定 / 取消；未填写密钥或调用服务 | M2 / M4 / M6：凭据管理、模型配置、按场景接入连接器 |

这些是产品元数据，允许保留名称、图标和用途。用户内容始终由真实创建和执行产生；预设不会重新填入已清除的开发样例。

## 导航和键盘边界

菜单上下键选择功能；右方向键进入该行图钉，左方向键回到功能名称；Enter / Space 执行，Escape 关闭。操作图钉后菜单仍打开并保持焦点，达到四项时其余图钉禁用，功能说明仍可查看。

弹窗固定按钮与菜单、外栏同步。关闭后返回有效入口。角色的「切换角色」复用侧栏人物选择菜单，选择不更换当前会话；「开始 / 继续对话」共用 `continueCompanion`，新会话绑定所选人物，已有会话保留自己的角色。Agent 工作区的「查看会话活动」只打开已有活动视图；已打开活动时不反向关闭它。

固定功能与四个导航分类分开管理。分类拖动不包含「更多功能」或固定入口；打开预设不进入内容历史，也不改变普通 / Coding 模式。待后续真实模块就绪，再把对应入口接到明确的管理视图或窗口。

## 实现与验收

`feature-model.ts` 定义目录，`feature-view.ts` 渲染，`feature-actions.ts` 处理交互，`features.css` 管理紧凑菜单与弹窗。`state.ts` 只管理固定偏好，`workspace-storage.ts` 校验恢复；原存储键保持不变。

最初功能预设迭代保留 85 项回归并增加五项固定偏好测试，共 90 项。后续侧栏信息组织增加六项，角色切换再增加八项，当前共 104 项并全部通过。角色选择、取消、按人物继续、创建绑定、旧偏好恢复、归档保留身份与详情均有验证；浏览器和原生的实际检查范围见 [导航闭环验收](navigation-contract.md)。后续接入时继续按此边界检查内容 ID、窗口共享状态和真实结果。
