## 当前基线

已实现导航壳、顶部内容操作、产品功能预设、内侧栏信息组织和五位人物切换，现有测试 104 项；2026-10-04 本轮全部通过。人物选择偏好和已有会话身份分别保存，开始 / 继续入口按人物复用真实会话。真实会话正文、模型服务、Pi 运行时、数据库、Live2D 与工作流未实现，主区保持占位。实际依赖与脚本以 [package.json](../package.json)、[Cargo.toml](../src-tauri/Cargo.toml)及锁文件为准。

研究与迭代文档编写后，侧栏及顶部栏继续迭代；功能预设只提供用途说明、固定偏好和已有角色 / 活动操作。最新代码范围、示例清理及浏览器 / 原生验收分别记录在 [README](../README.md) 和导航文档中。

## 文档维护规则

- **当前事实**放在 README 和导航文档；**目标行为**放在产品、架构、存储和计划文档。完成代码及验收后才更新为已实现。
- 产品语义以产品定义为准，存储权威与迁移以会话文档为准，开发状态以任务清单为准；同一事实不在多个文档维护不同版本。
- 一个任务完成须记录代码位置、测试或原生验收证据和适用平台。状态为“待开始 / 进行中 / 待验收 / 已完成 / 阻塞”，负责人在领取时填写，本轮不虚构人员和工期。
- 更新上游依赖时同时核对 SDK、事件结束条件、会话格式、恢复和分发；研究文档中的 commit 只是调研快照，不等于项目已经安装该版本。
- 图标、菜单、归档、角色入口等已有导航约定在后续接入中作为回归要求。当前按用户要求预设后续能力入口，必须标明「待接入」；真实操作达到闭环后才替换用途说明，不显示虚构成果。
- 计划中的目录不是当前文件。使用相对路径链接仓库文件；新增文档同步更新此索引。研究来源使用官方网页或固定 commit 链接，并记录核对日期。
