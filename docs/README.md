当前侧栏提供工作台与联系人入口，底部账号保留。工作台首页为猫图标、问候、文本输入区和快捷提示；右侧辅助区显示工作台历史并可调整宽度。联系人在主区采用紧凑列表和连续聊天，包含五位官方同伴、自建联系人搜索及顶部新增。已打开的联系人分别保留当前页面中的草稿与流式状态。

聊天正文由共享 ChatHistoryStore 按 ID 合并到浏览器存储，联系人复用最近的相同 contact.id 会话并保留 thread.id；工作台对话独立。该实现不代表 SQLite、跨设备同步或原生多窗口执行已经验收。模型调用路径使用 Vite 开发 / 预览服务器的环境变量，本机模型配置记录尚未驱动该路由；未连接时禁用发送，不生成演示回复。

当前设置为 30 个分类。灵动岛与 Live2D 桌宠保留设置页，运行功能暂未接入。账号能力依赖已配置的服务；语音、电脑操控、SSH、Coding 执行层和 Hooks 的配置仍不等于运行能力可用。应用源码见 [领域目录](../src/app/README.md)，依赖及脚本以 [package.json](../package.json)、[Cargo.toml](../src-tauri/Cargo.toml) 及锁文件为准。

## 文档维护规则

- 当前行为放在 README、导航和设置文档的当前事实段；目标能力放在产品、架构、存储与计划文档。完成代码与对应验收后才更新完成状态。
- 产品语义与数据权威分别有明确契约；相同对象保持 ID，状态由领域模块拥有，界面只呈现真实数据和执行结果。
- 一个任务完成须记录代码位置、测试或原生验收证据和适用平台；本轮不虚构人员、工期、测试数量或模型接入状态。
- 研究文档中的固定提交是调研快照，不等于已安装依赖。更新服务时重新核对协议、事件结束条件、恢复和分发。
- 计划目录不是现有文件；使用相对路径链接仓库文件，新增文档同步更新此索引。保留历史证据时标明日期、入口与未覆盖范围。
- 运行时分发、SQLite 单写权威、真实提供方、Live2D 资源和公开发行平台仍需分别验证，按实际通过的证据扩展产品承诺。
