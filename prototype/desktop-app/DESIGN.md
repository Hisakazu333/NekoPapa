# NekoPapa 设计系统 2.0（DESIGN.md）

> 唯一真相源。所有原型页的新建/修改必须遵守。
> 方法论来源：Linear（accent scarcity、surface ladder、8px 矩形按钮、负字距）+ Notion（六级灰阶、分组标签字距、颜色角色分工），分析自 VoltAgent/awesome-design-md。

## 一句话

**安静的界面，鲜艳的她。** 界面退到中性（黑白灰），粉色只属于"她"和"学习本身"。

## 颜色纪律（Accent Scarcity）

粉色（--tPrimary #E06B97）只允许出现在：

1. 她的存在：连续天数、她的话里的动作词、她的气泡/头像描边
2. 她的动作：发送键、偷袭复习、庆祝
3. 运行中状态：旋转指示、运行点
4. 当前选中：会话左侧 2.5px 指示条

**禁止**：开关、普通徽章、普通按钮、边框强调使用粉色。

| 角色 | 值 |
|---|---|
| 主按钮 | --tInk1 深色矩形（8px），hover #2A303B |
| 次按钮 | 白底 + rgba(24,28,35,.08) 发丝线边框 |
| 开关 on | --tInk1（macOS 原生感） |
| 徽章 | 默认中性灰；粉色徽章仅用于"她的"信息 |
| 边框 | rgba(24,28,35,.06~.08)，hover 加深到 .16 |
| 文字 | ink1 #181C23 / ink2 #4E5763 / ink3 #8D95A3 |

## 圆角纪律

- 按钮/输入/小控件：**8px（矩形，禁止胶囊按钮）**
- 卡片：12px
- 面板/弹层/窗口：14~16px
- 胶囊仅用于：分段选择器、状态点、头像

## 字体排印

- 页面标题：18~21px / 600 / 负字距 -.02em（禁止 700+）
- 分组标签：10~10.5px / 600 / letter-spacing .09em
- 正文：12.5~13px / 400~500
- 辅助：11~11.5px / ink3
- 数字：font-variant-numeric: tabular-nums（时间、进度、统计不错位）

## 层级（Elevation）

不用重阴影。层级 = 表面阶梯 + 发丝线：
L0 基底 #F3F5F9 → L1 侧栏 #E9EDF3 → L2 卡片白 + hairline → L3 弹层白 + shadow-lg。
阴影只用 proto.css 的 shadow-sm/md/lg（已调淡）。

## 密度（指针思维）

- 行高：导航 28px、列表 26~30px、行 padding 9~11px
- 控件高：按钮 28~30px、开关 38×22、输入 26~32px
- 侧栏：216px

## 交互

- 过渡：120~220ms，ease-out；弹性只给她（cubic-bezier(.34,1.56,.64,1)）
- hover：背景 rgba(24,28,35,.05) 或边框加深，不用位移+变色双效
- 焦点环：rgba(224,107,151,.5) 边 + 3px 12% 粉光晕（仅输入类）
