收到，题我拆好了，看右边 👉 先说结论：这题考先行词被 the only 修饰时只能用 that。
你选 B（which）是掉进了最常见的坑——which 本身没错，但 the only + 先行词 后面关系词必须用 that，考试就爱考这个。
这道已经帮你收进错题本了，错因标的「the only 后用 that」。点顶上「举一反三」再练两道确认真懂了 👆
题目 · 她识别出来的
This is the only book ____ I bought last year.
A. who B. which C. that ✓ D. whom
句子拆解 · 主从句标色
This is the only book 主句
that I bought last year 定语从句 · 修饰 book
考点：先行词被 the only / the very / 序数词 修饰时，关系词只能用 that，不能用 which。
同考点速记 · 一句话
看到 the only / the best 开头，闭眼选 that
例外：非限制性定语从句（有逗号）里 that 再对也不能选
举一反三 · 第 1 / 2 题 · 她刚出的
The first thing ____ we should do is to finish the report.
Awhich
Bthat
Cwho
Dwhom
✓ 对！序数词 the first 修饰先行词，和 the only 是同一家族——只能 that。这个考点你算是拿下了。
