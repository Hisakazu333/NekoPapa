# Live2D Assets

`hiyori/` contains the official Hiyori (Momose Hiyori) sample model used by
the embedded Web Live2D canvas. A compatible external Native Stage may also
load the bundled model through the path supplied by the Tauri host.

The model is Live2D Free Material. It is not an original Lumia asset and is
not covered solely by this repository's Apache-2.0 license. Use and
redistribution must follow Live2D's Free Material License and the model's
individual terms. Cubism Core and Native SDK components are governed by
Live2D's applicable proprietary terms.

This repository no longer contains the Cubism Native SDK. The external Native
Stage producer is responsible for shipping the applicable SDK notices and for
confirming that the final desktop package satisfies redistribution terms.
